# Промпти для арту

_Згенеровано з даних гри: `npm run art-prompts` (scripts/artPrompts.ts). Не правити руками — правити дані й перегенерувати._

## Стиль

- Спільний хвіст кожного промпту: `top-down view (straight from above), hand-painted 2D game sprite, clean readable silhouette, soft shading, slight outline, transparent background, no text, no shadow on the ground`.
- Вид строго згори; те, що повертається в бою (герой, вороги, боси), — «обличчям праворуч».
- PNG з прозорим фоном; файл кладеться в `public/sprites/<вид>/<id>.png` і записується в `public/sprites/index.json`.

| Вид | Розмір | Повертається |
|---|---|---|
| Герой (клас або гілка) (`hero`) | 96×96 | так |
| Ворог (`enemy`) | 96×96 | так |
| Бос або мінібос (`boss`) | 192×192 | так |
| Річ (іконка) (`item`) | 64×64 | ні |
| Перешкода арени (`obstacle`) | 128×128 | ні |
| Предмет у місті (`prop`) | 96×96 | ні |
