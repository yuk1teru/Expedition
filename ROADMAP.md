## Правила для кожного етапу

- Працювати від першого невиконаного пункту. Після кожного пункту чи логічного блоку — коміт (без співавторства Claude).
- Усе, що побачать гравці, — запис у «Що нового» з новою версією.
- Нові дані — у `src/data`, з показом у вікі (`src/wiki/sections.ts`), щоб їх можна було правити.
- Тести перевіряють **правила, а не конкретні числа**: числа змінюються у вікі.
- Нову механіку бот має як мінімум не ламати: швидка перевірка «без падінь і зависань». Повний баланс — блок K реворку.
- Відкриті питання з VISION.md вирішуються на початку того етапу, якого вони стосуються.
- Перевірка перед комітом: `npm run typecheck && npm test && npm run build`; візуальне — знімок через CDP.
