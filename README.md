# Експедиція — вертикальний зріз

2D-рогалик з автобоєм: герой б'ється сам, гравець вирішує, коли використати скіли. Зараз реалізовано вертикальний зріз (SLICE.md): маршрут → бій з ручними скілами → прокачка → бос. Повна специфікація — у SPEC.md, план повного прототипу — у PLAN.md.

## Запуск

```bash
npm install
npm run dev        # гра на http://localhost:5173
npm run build      # typecheck + production-збірка в dist/
npm run preview    # перегляд збірки
npm run typecheck  # tsc --noEmit
npm test           # vitest
npm run sim        # міні-симуляція балансу (200 прогонів)
npm run sim -- --no-skills          # бот без скілів
npm run sim -- --runs 500 --seed 42 # інша кількість прогонів / seed
npm run probe                       # на якій хвилі гине бот (один візит у гай з 1-го рівня)
npm run probe -- --endless --level 10  # нескінченний режим: як глибоко заходить герой 10 рівня
```

Seed забігу показано в правому верхньому куті карти. Задати його можна через URL: `http://localhost:5173/?seed=123`.

## Деплой (GitHub Pages)

Кожен пуш у `main` запускає `.github/workflows/deploy.yml`: `npm ci` → typecheck → тести → `npm run build` → публікація `dist/` на GitHub Pages. Гра доступна за адресою `https://yuk1teru.github.io/Expedition/` (можна додавати `?seed=123`). Відносні шляхи в збірці задає `vite.config.ts` (`base: './'`). Одноразово в репозиторії треба увімкнути **Settings → Pages → Source: GitHub Actions**. Дебаг-панель у публічній збірці вимкнена.

| Напрямок Ривка й Удару об землю | курсор миші на арені (курсор поза ареною — автонаведення) |

| Трава й зілля | `Z` / `X` / `C` у бою — що стоїть на слотах, обирається в інвентарі (перетягнути або ПКМ → «Поставити на…») |
| Ривок черевиків | `Shift` — ривок у напрямку руху (стоїте — куди дивиться герой); зелені черевики й кращі |
| Торговець | кнопка в місті: купити лупу, зілля (мале / звичайне / велике) або випадкову річ для обраного слота (120 зол., зелена–епічна, одразу розпізнана); обрати річ у сумці — розпізнати (`R`), вдягнути (`E`) або продати; `Tab` — повне спорядження поверх торговця |
| Пауза | `Esc` або кнопка «Пауза»; на паузі — список керування і «Завершити забіг (поразка)» |
| Швидкість ×1/×2 | кнопка в правому верхньому куті бою |
| Вибір картки / класу | клік або `1`–`3` (перші 1.5 с вибір заблоковано); `R` — перекинути картки за золото; наведіть на скіл — усі 5 рангів |
| Вибір стартових скілів | клік або `1`–`8`, `Enter` — підтвердити |
| Кнопки меню | клік, `Tab` + `Enter`, гарячі клавіші (`1`/`2`/`3` у місті, `Enter` на екранах результатів, `Esc` у спорядженні) |
| Дебаг-панель (лише `npm run dev`) | `` ` `` |

Дебаг-панель: +1 рівень, +1000 золота, вбити всіх, безсмертя, перейти до боса, скинути лічильник проходжень гаю. У dev-збірці стан гри доступний у консолі як `window.__app`.

## Що є у зрізі

- Місто: кожен візит — автоматичний відпочинок (повне лікування + чекпоінт); спорядження, торговець; карта з 3 вузлів: Місто, «Тихий гай», «Лігво Старого Ената».
- Гай стає складнішим з кожним проходженням: `tier = 1 + 0.5 × проходження`, максимум 3. У боса фіксований tier 2.5 (рек. рівень 8).
- Біом Ліс, у кожного ворога одна помітна риса: Вовк — припадає до землі (видно пунктир стрибка) і стрибає, укус сповільнює на 30%; Гриб-плювака — світиться перед пострілом, кожен 3-й постріл — віяло з 3 спор (світіння більше й рожеве); Пеньок — тупотить: червоне коло навколо себе, з якого треба вийти. Елітна версія з аурою.
- Пастки (з 4-ї хвилі): сталеві капкани на арені, з кожною хвилею їх більшає (до 7). Капкан тримає героя 1.1 с (ні руху, ні Ривка) і ранить. Ривок їх перестрибує.
- Події кожної 5-ї хвилі по черзі: погода (Гроза — блискавки під героєм з телеграфом; Туман — видно лише поруч; Злива — −25% руху, −15% швидкості атаки) до кінця хвилі, або Дух бурі — крихкий снайпер, що тримається далеко, стріляє віялом швидких снарядів, які лише сповільнюють (без шкоди), і раз на 30 с відстрибує з поривом вітру, коли герой поруч.
- Локація: хвилі йдуть без кінця, кожна сильніша за попередню — окремо HP (1 + 0.07·i + 0.03·i²), шкода (1 + 0.13·i + 0.018·i²), швидкість (+2.5% за хвилю, до ×1.5), досвід (1 + 0.05·i + 0.025·i²) і золото (лінійно: 1 + 0.06·i); таблиця — нижче. Швидкі й дальні вороги отримують лише 60% приросту HP, танки — 115%. Після 3-ї хвилі ворогів більшає на 1 щоразу, але не більше 28. Кожна 3-тя хвиля приводить мінібоса «Ватажок зграї» (ривок по лінії, стрибок на героя, виклик вовків; зрідка ривок і стрибок ідуть комбо одне за одним — «Комбо!»: 20% / 15%), посиленого так само. Після кожної 3-ї хвилі на краю арени відкривається портал на 15 с — зайшли (кнопка «Увійти» або `E`) — нагорода; інші перерви — 5 с. Будь-яку перерву можна пропустити (`N`). Бос і мінібос виділені колом на землі й мають над собою ім'я та смугу HP.
- Повторний вхід у локацію, яку вже проходили: вибір «Продовжити з хвилі N+1» (з тією ж силою хвиль, до порталу знову 3 хвилі) або «Почати з 1-ї хвилі». На екрані нагороди — обов'язкові хвилі й скільки пройдено (з якої по яку).
- Черевики дають +10–13% швидкості руху (× сила рідкості); зелені й кращі — ривок на `Shift` у напрямку руху: 70 / 95 / 120 / 150 px, перезарядка 15 / 14 / 13 / 12 с (незвичайні → легендарні), слот «Shift» поруч зі слотами Z / X / C.
- Спорядження: зброя, капелюх, броня, черевики. 5 рідкостей (Звичайна, Незвичайна, Рідкісна, Епічна, Легендарна) — сильніші й з більшою кількістю характеристик. По 5 типів предмета на слот (меч, сокира, булава, кинджал, спис…), кожна річ має унікальний вигляд: форма типу + колір рідкості + власний акцент і самоцвіт. Мінібос дає 1 річ (переважно звичайні–рідкісні), бос — 2 (рідкісні–легендарні).
- Речі падають нерозпізнаними («???») у сумку; щоб вдягнути, треба використати «Лупу» (купується в торговця, можна використати і в бою через інвентар). Поки є непереглянуті речі, блимає «Нова річ — Tab». Торговець купує речі (ціна за рідкістю, нерозпізнані — за пів ціни).
- Рослинки: на початку кожної 2-ї хвилі на арені може вирости рослинка (не більше 2): трава трьох кольорів — зелена (4% макс. HP + 8 HP за 4 с), червона (7% + 15), біла (11% + 25), до 3 кожної, переносяться між боями; «Ягода люті» — +30% швидкості атаки на 8 с. Зілля продає торговець: мале (15% + 10 HP за 3 с, 20 зол.), звичайне (25% + 15, 45 зол.), велике (40% + 20, 90 зол.). Усе лікує поступово (і під ударами); між двома лікуваннями — 1 с. Трава й зілля використовуються зі швидких слотів `Z` / `X` / `C`: нова — сама стає на вільний слот, решту гравець розставляє в інвентарі.
- Герой відновлює 2 HP/с у бою, але лише якщо 1.5 с не отримував шкоди (реген не перекриває шкоду в сутичці); вампіризм лікує і від скілів (зелені цифри раз на пів секунди). Інвентар (`Tab`): фігура людини з речами на голові, тілі, в руці й на ногах, сумка іконками, клік — вдягнути/зняти.
- Візуал атаки: серп удару по дузі, ривок тіла героя вперед, біле кільце на цілі; кільце навколо героя заповнюється до наступного удару (золоте й пульсує, коли атака готова); швидкість атаки — в HUD.
- Автоатака залежить від класу (`basicAttack` у `src/data/classes.ts`): новачок б'є одного ворога у вузькій дузі 50°, Воїн — дугою 140°, ціль отримує повну шкоду, інші в дузі — 40% (сірі цифри). Для Мага й Лучника атака лише описана.
- HUD: HP — смуга з числом під героєм; рівень і смуга досвіду — внизу біля скілів; згори — клас і характеристики, хвиля/HP боса, золото й день. Керування — у вікні «Як грати» на старті та на екрані паузи.
- Смерть не закінчує забіг: герой повертається в місто зі станом останнього візиту туди. Перемога над босом сама зберігає чекпоінт; після екрана перемоги можна продовжити експедицію. Завершити забіг можна з паузи.
- Ручний рух (`WASD`), наведення Ривка й Удару об землю мишею, перестановка скілів перетягуванням.
- Рівні 1–15: на 1–2 лише автоприріст (+15 HP, +2 атаки), на 3-му вибір класу (Воїн; Маг і Лучник — «Незабаром»; у вікні видно всі скіли класу з рангами і пасивки з максимумом стаків), на 4–15 — вибір з 3 карток. Картки й вибір класу перші 1.5 с не реагують на клавіші (смужка «вибір через …»), щоб натискання скілів не обрало картку випадково.
- Воїн: 8 скілів — Вихор, Ривок, Бойовий клич, Удар об землю, Кидок сокири, Залізна шкіра, Землетрус, Гак (ранги 1–5: 2 і 4 — числа, 3 і 5 — особливі модифікатори; підказка будь-де показує всі ранги — ✓ взяті, ▸ наступний). Після вибору класу гравець сам обирає 3 з 8, 4-й приходить карткою. Описи скілів кажуть, від чого рахується шкода (% атаки героя) і яка перезарядка. Пасивки: Броня, Вампіризм (5% за стак), Бойовий азарт (кожне вбивство −0.15 с перезарядки всіх скілів за стак).
- Картки: можна «Перекинути» за золото (20, далі +15 за кожне перекидання) або «Пропустити» — золото (10 + 3 × рівень) і баф на 12 с: +5 HP/с, +20% шкоди, +20% швидкості руху (поза боєм — з наступним боєм).
- Бос Старий Енат: коріння (телеграфи під героєм), призов вовків, удар навколо себе; друга фаза на 50% HP.
- Екрани нагороди, смерті й перемоги; «соковитість»: цифри шкоди (криты більші й жовті), білий спалах при влучанні, частинки, тряска (вимикається при `prefers-reduced-motion`), хіт-стоп, кільце нового рівня, «+N золота», поява ворогів зі зростанням.
- Міні-симуляція балансу `npm run sim`.

## Структура

```
src/
  main.ts            вхід: полотно, ввід, App
  core/              RNG (mulberry32 + fork), seed, стан забігу, екрани й модальні вікна, цикл, ввід, шина подій
  data/              УСІ числа і контент: balance, biomes, enemies, skills, classes, bosses, fx
  systems/           логіка без DOM: mapgen, run, battle, combat, ai, collision, waves, leveling,
                     scaling, targeting, effects, cards, boss, hero
  systems/skills/    реєстр скілів (index.ts) + реалізації класу (warrior.ts)
  systems/bosses/    поведінка босів і мінібосів (enat, alpha, galeSpirit), реєстрація в index.ts
  render/            полотно, UI-примітиви, екрани, HUD, ефекти, модальні вікна, дебаг-панель
scripts/sim.ts       безголова симуляція; scripts/bot.ts — бот; scripts/probe.ts — смерті бота по хвилях
tests/               rng, mapgen, formulas, cards, boss, waves, skills, progress, pickups, controls
```

Логіка (`src/core`, `src/systems`, `src/data`) нічого не імпортує з `src/render` і не звертається до DOM/window — тому `npm run sim` працює в Node.

## Де міняти баланс і контент

- **Числа героя, прогресії, хвиль, масштабування, золота, симуляції** — `src/data/balance.ts`.
- **Вороги** — `src/data/enemies.ts` (запис з архетипом `chaser | shooter | tank | fast`); список ворогів біому — `src/data/biomes.ts`.
- **Скіли й пасивки** — `src/data/skills.ts` (параметри рангу 1, правило рангу 2 і модифікатор рангу 3); реалізація — функція в `src/systems/skills/<клас>.ts`, зареєстрована в `src/systems/skills/index.ts`.
- **Класи** — `src/data/classes.ts` (пул скілів і пасивок для карток).
- **Боси** — `src/data/bosses.ts` (статистики, таблиця атак з вагами, кулдаунами й параметрами по фазах) + поведінка в `src/systems/bosses/<бос>.ts` через `registerBoss`.
- **Відчуття** (тряска, хіт-стоп, частинки, цифри) — `src/data/fx.ts`.
- **Речі, рідкості, типи, таблиці здобичі, ціни продажу** — `src/data/items.ts` (вигляд — `src/render/itemArt.ts`). **Лупа, трава, зілля, швидкі слоти, рослинки** — `src/data/consumables.ts`. **Хвилі, портал, додаткові хвилі** — `WAVES` у `src/data/balance.ts`; **події 5-ї хвилі, пастки** — `WAVE_EVENTS`, `TRAPS` там само; **погода** — `src/data/weather.ts`; **риси ворогів** (стрибок, віяло, тупотіння, сповільнення) — поля `dash`, `volley`, `stomp`, `cripple` у `src/data/enemies.ts`. **Мінібос локації** — поле `miniboss` біому + запис у `src/data/bosses.ts` (`miniboss: true`) + поведінка в `src/systems/bosses/`.

## Рішення прототипу

1. **Топологія зрізу.** Обидві локації з'єднані з Містом (2 ребра), тому лігво боса доступне з самого початку, а між боями завжди можна зайти в місто. Вхід у локацію завжди запускає бій; клік по поточній локації — повторне проходження без лікування.
2. **Ядро без DOM.** `GameLoop` отримує планувальник кадрів (`requestAnimationFrame`) ззовні, `bindInput` — джерела подій, `ScreenManager` узагальнений за типом контексту рендеру. Тільки `main.ts` і `src/render` торкаються `window`.
3. **Досвід і золото — за кожне вбивство**, бонус золота — за зачистку. Підвищення рівня посеред бою ставить гру на паузу і відкриває вибір (клас / картка). Черга виборів зберігається в `GameState.modalQueue`, тому кілька рівнів поспіль обробляються по черзі.
4. **Масштабування досвіду**: досвід ворога росте з tier так само, як HP (+45% за tier). Штраф досвіду (25%, якщо герой на 4+ рівні вище рекомендованого) реалізовано, хоч у зрізі він майже не спрацьовує.
5. **Посилення ворогів від днів** реалізоване формулою, але вимкнене в зрізі (`SCALING.dayThreat.enabled = false`). Лічильник днів росте.
6. **Бойовий клич, ранг 3** «+20% броні»: у героя базова броня 0, тому трактується як −20% отриманої шкоди на час дії (видно як сталевий шестикутник навколо героя). **Провокація** змушує стрільців припинити тримати дистанцію і підійти впритул — вигідно для Воїна.
7. **Ривок** дає невразливість на час стрибка; якщо на арені є телеграфи боса, точка приземлення шукається поза ними (біля тієї ж групи) — так від коріння можна втекти Ривком.
8. **«Немає цілі»**: Вихор вимагає ворога в радіусі 150 px, Ривок — групи в межах 300 px, Удар об землю — ворога в конусі, Бойовий клич — будь-якого живого ворога. Інакше кулдаун не витрачається, слот спалахує червоним.
9. **Ранг 3** = значення рангу 2 (+30% шкоди, −10% кулдауну) + модифікатор.
10. **Стрільці** відступають повільніше, ніж ходять (40% швидкості), інакше ближній бій перетворювався на погоню.
11. **Коріння Ената**: одне коло завжди під героєм, решта — на відстані 80+ px, щоб не накладатися на героя кількома колами одразу.
12. **Призвані ворогами** боса дають досвід, але не золото; зі смертю боса гинуть і вони. Після перемоги над босом (єдиним у зрізі) одразу показується екран перемоги.
13. **Хіт-стоп** реалізований у рендері (пропуск кроків симуляції), тож на симуляцію балансу не впливає.
14. **Числа рендеру**: геймплейне «відчуття» (тривалості, тряска, кількість частинок) — у `src/data/fx.ts`; координати розкладки UI й кольори інтерфейсу лишаються в `src/render`.
15. **Пропозиція карток**: якщо валідних карток менше трьох, пропонується менше; якщо жодної — вибір пропускається.
16. Версії інструментів на момент створення: TypeScript 7, Vite 8, Vitest 5, tsx 4.

Після першого плейтесту (етап G у SLICE.md) кілька рішень SPEC.md змінено на прохання гравця:

17. **Ручний рух і атака за мишею.** SPEC описує повністю автоматичний рух; тепер герой гравця ходить лише від `WASD`/стрілок, а автоатака б'є найближчого ворога в дузі 120° в бік курсора (дальній бій — стріляє вздовж прицілу, якщо в конусі 50° є ворог). Курсор поза ареною — атака триває в останньому напрямку. Від коріння боса й снарядів можна відбігти; стрілець світиться 0.6 с перед пострілом, снаряд летить туди, де був герой. Автохід до ворогів лишився тільки в бота симуляції (`input.control = 'bot'`), тож симуляція оцінює баланс для «ідеально автоматичного» героя, а не для живого гравця.
18. **Наведення мишею** для скілів з напрямком (`aimable` у даних): Ривок летить до курсора (до своєї дальності) і тоді не потребує цілі; Удар об землю б'є конусом до курсора, якщо на арені є вороги. Курсор поза ареною (наприклад, клік по слоту) — автонаведення.
19. **Перестановка скілів** — перетягування в панелі; слоти без «дірок»: перетягування на порожній слот ставить скіл останнім.
20. **Портал замість автоматичного кінця бою.** Вихід з локації — лише крок у портал, і лише під ручним керуванням (або коли на полі нікого): автобій не виносить героя в портал випадково. Додаткові хвилі стартують через 5 с після попередньої. Нагорода (бонус золота, +1 до складності гаю, +1 день) — при виході.
21. **Мінібоси** використовують ту саму систему, що й боси (таблиця атак, телеграфи), плюс контактний удар і ривок по лінії; фаза 2 для них не обов'язкова.
22. **Чекпоінт** знімається на старті забігу і при кожному потраплянні в місто (окремої кнопки «Відпочити» немає — відпочинок автоматичний). Смерть відновлює героя (рівень, клас, скіли, речі), золото, день і прогрес карти з чекпоінта; статистика забігу (вбивства, шкода, час, смерті) зберігається. Таймер гри стоїть на екранах смерті й перемоги. Кнопка «Новий забіг» лишилась на екрані смерті як опція.
23. **Речі**: рідкість визначає силу (звичайна — тільки основна характеристика, епічна — сильніша основна + додаткова). Рівня речі поки немає.

Після другого плейтесту (етап H):

24. **Слоти скілів** — кожен скіл пам'ятає свій слот (`HeroSkill.slot`), тож слоти можуть бути з пропусками; новий скіл займає перший вільний слот.
25. **HP боса/мінібоса** — лише у верхній панелі HUD (центральний блок), арена нічим не перекрита.
26. **Виправлено баг**: ШІ звичайних ворогів обнуляв швидкість босам, тому Енат стояв на місці, а Ватажок «зависав» після першого ривку. Тепер обидва ходять; баланс перераховано.
27. **Портал** відкривається на краю арени (34 px від краю), подалі від героя; вхід — тільки кнопкою «Увійти в портал» або `E`, коли герой у межах 40 px. Ні рух, ні штовхання ворогів у портал не затягують.
28. **Ривок** при наведенні летить точно до курсора (до 300 px) і б'є всіх ворогів на шляху (смуга 56 px) та навколо точки приземлення — кожного один раз.
29. **Інвентар** — модальне вікно (пауза), а не окремий екран; кнопка «Спорядження» в місті відкриває те саме вікно.

Етап I:

30. **Автоатака класу — дані, а не код героя**: `BasicAttackDef` (`melee`: дуга + частка сплешу; `ranged`: поки лише опис). Новачок і Воїн реалізовані; Маг (снаряд + опік впритул) і Лучник (прострілювання) описані у вікні вибору класу. Бот симуляції б'є так само (зі сплешем), тому баланс перераховано.
31. **Сплеш** не робить окремого кидка криту: інші цілі отримують 40% від уже кинутої шкоди основної цілі (і крит, якщо він випав).
32. **«Як грати»** показується один раз при запуску гри; той самий список керування — на екрані паузи.

Етап J:

33. **Тряска на паузі** — баг: поки відкрите вікно вибору картки чи пауза, таймер тряски стояв, а зсув рахувався щокадру. Тепер на паузі зсуву немає, ефекти (портал, банери) догравають після вибору.
34. **Портал** активний лише в перерві між хвилями; під час хвилі він тьмяний і не працює. Перерва між додатковими хвилями — 10 с (було 5), щоб встигнути дійти до краю арени.
35. **Перемога над босом** зберігає чекпоінт (смерть після неї не відкочує перемогу) і показує екран перемоги лише першого разу (`runCompleted`); далі — звичайний екран нагороди. «Продовжити експедицію» повертає на карту з усім прогресом.
36. **Речі** лише в сумку з позначкою «НОВЕ»; позначки знімаються, коли закрити інвентар. Бот симуляції вдягає речі в порожні слоти — як зробив би гравець, тому баланс не змінився.
37. **«Завершити забіг (поразка)»** на паузі потребує другого кліку протягом 3 с; незавершений бій зараховується в статистику, далі — екран «Забіг завершено» і «Новий забіг». Час гри стоїть на екранах смерті, перемоги й завершення.

Етап K:

38. **Вампіризм** і раніше працював від усіх джерел шкоди, крім шипів, але лікування не показувалось. Тепер воно сумується й показується зеленою цифрою раз на 0.5 с; регенерація 1 HP/с цифр не показує.
39. **Броня**: формула м'якша (`k = 200`: 50 броні — −20%, 100 — −33%), пасивка «Броня» +6 за стак (було +8), броня в речах — 4–6 × сила рідкості.
40. **Розпізнавання**: нерозпізнану річ видно як «???» з силуетом типу й кольором рідкості; її можна продати за пів ціни. Лупа витрачається на одну річ.
41. **Вдягання** — тільки перетягуванням на фігуру/слот або через ПКМ-меню; простий клік лише підказує, як це зробити. Перетягнута у сумку вдягнута річ знімається.
42. **Рослинки** з'являються на початку парних хвиль (бонусні теж), у випадковому місці не ближче 120 px до героя; виростають за 2 с, після чого їх можна підняти, зайшовши на них. Якщо трави вже 3, нова лишається рости. Бот симуляції рослинки не збирає, але їсть траву нижче 40% HP.
43. **Бот і речі**: після кожного бою купує лупи на нерозпізнані речі (якщо вистачає золота), розпізнає й вдягає в порожні слоти.

Етап M:

44. **Ріст хвиль** — квадратичний: ранні хвилі майже як раніше, далі сила росте все швидше. Кількість ворогів росте лише після першого порталу, щоб перший гай лишався прохідним для новачка.
45. **Портал** розміщується один раз (на краю арени) і відкривається після кожної 3-ї хвилі на 15 с; кожне відкриття — банер «Портал відкрито на 15 с!». У верхньому HUD видно, через скільки хвиль буде портал.
46. **Мінібос** — кожна 3-тя хвиля, його HP/шкода/досвід/золото множаться на силу хвилі; удар-ривок 3 → 4, ближній удар ×1.3, телеграф 0.8 → 0.7 с.
47. **Скіли класу**: пул — 8 скілів; старт — 3 на вибір гравця (бот бере Вихор, Ривок, Удар об землю), 4-й слот заповнюється карткою «Новий скіл» з решти 5. Ранг 1 обраних скілів.
48. **Пропуск картки** дає баф з полями `damageMult`, `moveSpeedMult`, `regen`; ці поля враховують і автоатака, і скіли (через `heroAttack`), і регенерація.

Після плейтесту етапу M (етап N):

49. **Ранги 1–5** замість 1–3: кожен скіл у даних має параметри рангу 1 і 4 покращення з абсолютними значеннями (`upgrades`); ранги 3 і 5 — особливі модифікатори з текстом, числові зміни описуються автоматично («шкода 60% → 72%»). Максимальний рівень піднято до 15 (12 карток), бо прокачати 4 скіли до 5 рангу за 7 карток неможливо.
50. **Затримка карток** 1.5 с (`CARDS.inputDelay`) — і для вибору класу; кнопки «Перекинути»/«Пропустити» теж чекають.
51. **Гак** оглушає підтягнутих уже з 1-го рангу (0.8 с), тож швидкі вороги не кусають одразу після притягування.
52. **Землетрус**: радіус 160 → 110, сповільнення 40% → 25% (0.8 с), шкода 90% → 60%; оглушення лише на 5-му рангу (0.3 с). **Ривок**: дальність 300 → 240, оглушення 1 → 0.6 с, перезарядка 7 → 8 с (дальність і оглушення ростуть на 4-му рангу).
53. **Проти кайту**: вороги швидшають з кожною хвилею, укус вовка сповільнює, капкани з 4-ї хвилі (Ривок під час капкана заблоковано — «Пастка!»), Злива сповільнює. Залізна шкіра 5-го рангу знімає й не пускає сповільнення/капкани/оглушення.
54. **Сила хвиль** розділена: HP росте круто (пізні хвилі довші), шкода — майже лінійно (між сусідніми хвилями не більше +16%), розмір хвилі обмежено 28 ворогами. Різкий «ваншот» на 13-й хвилі давав натовп: 33 вороги, кожен вовк б'є на 11.6, і всі доходять до героя за секунду. Тепер ворогів ≤ 23 на 13-й хвилі, а найсильніші удари (тупотіння, стрибок вовка, блискавка) мають телеграф.
55. **Реген** 1 → 2 HP/с, але тільки після 1.5 с без шкоди: у сутичці він не перекриває вхідну шкоду, а між сутичками лікує швидше. Базова шкода ворогів 1.6/1.6/2.6 → 1.8/1.8/3.
56. **Повернення з карти**: Місто завжди доступне (клік, кнопка, `Esc`), навіть якщо герой уже «стоїть» у місті.
57. **Продовження локації**: вузол пам'ятає `lastWave` — скільки хвиль пройдено за останній успішний вихід; продовження стартує з тієї ж сили (і тим самим tier гаю), обов'язкові — наступні 3 хвилі.
58. **Трава** не росте, якщо в сумці вже максимум (3) з урахуванням тієї, що вже росте; замість неї може вирости ягода.
59. **Бот симуляції** виходить з червоних кіл телеграфів (у бік від центру) — інакше тупотіння пеньків, яке гравець легко обходить, вбивало б бота. Через це бос став легшим для бота — Енату підняли шкоду.

Етап O:

60. **Залізна шкіра** — стійка, а не миттєвий щит: 6 с (8 с на 4-му рангу), −35% вхідної шкоди (−45% з 2-го рангу) і лікування 20% / 30% макс. HP протягом дії (через `regen` бафу, працює навіть під ударами). 3-й ранг: +25% шкоди героя на час дії — скіл для атаки, а не для «танкування»; 5-й — несприйнятливість до контролю.
61. **Трава** лікує 10% (було 25%): ресурс на крайній випадок, а не друге життя.
62. **Гак** більше не штовхає імпульсом (важкий пеньок пролітав 25 px): вороги летять по прямій зі швидкістю 1800 px/с до місця впритул до героя, незалежно від маси. Боса не висмикує — лише б'є й оглушує.
63. **Золото** рідкісне: 0.4 × tier за ворога, росте лише лінійно з хвилею (×1.54 на 10-й), дробові частини накопичуються між вбивствами. Мінібос 8, Дух бурі 12, Енат 100, бонус зачистки 10 × tier, пропуск картки 5 + рівень, ціни продажу речей удвічі нижчі. Перший гай дає ≈ 35 золота (≈ одна лупа), 15 хвиль — ≈ 250–300 (раніше гравці мали 6–10 тис.).
64. **Шипи прибрано**: «танкування» в грі не цікаве, а шипи ні з чим не поєднувались. Замість них — «Бойовий азарт»: вбивства скорочують перезарядку скілів; поєднується з Вихором/Землетрусом (багато вбивств) і Вампіризмом (більше скілів — більше лікування). Механіка шипів (`thorns`) лишилась у коді для інших класів.
65. **Складність понад бота**: гравець ухиляється й кайтить значно краще за бота, тому після налаштування по симуляції шкоду й HP хвиль додатково підняли (бот гине частіше, ніж у цілях зрізу, — це навмисно).

Етап P:

66. **Дальність удару = намальований клин**: дальність класу рахується від краю героя (40 px), а не від центру; ворог отримує удар, якщо хоч частково в клині. Раніше клин малювався на 54 px від центру, а бив на 40.
67. **Ривок мінібоса** має ліміт часу (відстань / швидкість + 0.25 с) і точку, притиснуту до арени: коли герой тілом або стіною блокує стрибок, Ватажок зупиняється, а не «застрягає» назавжди.
68. **Скіли з курсором над HUD**: напрямок — до курсора, притиснутого до краю арени (раніше — автонаведення, через яке Ривок писав «Немає цілі»). Бот курсора не має й наводиться автоматично.
69. **Ривок черевиків** — коротка невразливість на час польоту (~0.1 с), напрям героя не змінює (атака триває туди, куди цілиться гравець), блокується пасткою й оглушенням.

70. **Торговець** розпізнає, вдягає й продає обрану річ прямо у своєму вікні; `Tab` (або «Спорядження») відкриває інвентар поверх торговця, після закриття — назад до торговця.
71. **Комбо Ватажка** рідше: ривок → стрибок 40% → 20%, стрибок → ривок 35% → 15%.

72. **Лікування** — набір предметів з відсотком і фіксованою частиною (`heal: { pct, flat, duration }`): трава слабша й лише з арени, зілля сильніше й лише в торговця. Лікування йде через баф `regen`, тому працює під ударами, а різні предмети складаються. Спільна перерва 1 с не дає випити все за мить. Клавішу `G` замінили три слоти `Z` / `X` / `C`. Бот п'є найсильніше з того, що має, нижче 40% HP.

73. **Характеристики речей**: звичайна — 1, зелена й синя — 2, епічна — 3, легендарна — 4 (у кожного слота 3 додаткові, легендарна має їх усі).
74. **Покупка речі** в торговця: обирається слот, рідкість випадкова (зелена 60%, синя 30%, епічна 10%, легендарних і звичайних немає), річ одразу розпізнана й лягає в сумку. Ціна 120 — кілька проходжень гаю.
75. **Ривок черевиків** — у напрямку руху (`WASD`), а не до курсора: так ним ухиляються, не відводячи прицілу.

## Масштаб шкоди

Шкода ворога = база × tier (1 + 0.45·(tier − 1)) × хвиля (1 + 0.13·i + 0.018·i², i = номер − 1) × 1.5 для елітного. Після цього — броня героя: × 200 / (200 + броня). Нижче — для гаю з tier 1.5 (друге проходження), до броні:

|---|---|---|---|---|---|---|---|---|---|---|
| 1 | 1.00 | 1.00 | 2.0 → 2.2 | 3.9 | 5.9 | 17 | 13 → 13 | 1.0 | 1.00 | 1.00 |
| 5 | 1.68 | 1.81 | 3.3 → 4.0 | 7.1 | 10.6 | 31 | 17 → 15 | 1.9 | 1.10 | 1.24 |
| 10 | 3.88 | 3.63 | 7.6 → 8.0 | 14.2 | 21.3 | 62 | 27 → 20 | 4.5 | 1.23 | 1.54 |
| 13 | 5.92 | 5.15 | 11.6 → 11.4 | 20.2 | 30.3 | 88 | 33 → 23 | 6.9 | 1.30 | 1.72 |
| 15 | 7.58 | 6.35 | 14.9 → 14.0 | 24.9 | 37.3 | 109 | 37 → 25 | 8.9 | 1.35 | 1.84 |

Окремий удар звичайного ворога не вбиває героя 10+ рівня (~330 HP) з повного здоров'я; ривок Ватажка після 15-ї хвилі — уже серйозний (з телеграфом). Небезпечна сума: до змін на 13-й хвилі 33 вороги (≈15 вовків по 11.6, 8 грибів по 11.6, пеньки по 19) за секунду знімали 300+ HP, коли оточували героя. Тепер на 13-й хвилі 23 вороги, а сильні удари мають попередження.
