# Експедиція

2D-рогалик з автобоєм і кампанією: герой б'ється сам, гравець вирішує, коли використати скіли. Бачення — VISION.md, план — ROADMAP.md (етапи 0–8 — PLAN.md). Розділ «Що є у зрізі» нижче — історія першої версії.

## Запуск

```bash
npm install
npm run dev        # гра на http://localhost:5173
npm run build      # typecheck + production-збірка в dist/
npm run preview    # перегляд збірки
npm run typecheck  # tsc --noEmit
npm test           # vitest
npm run sim        # симуляція 200 повних забігів (класи по черзі)
npm run sim -- --no-skills          # бот без скілів
npm run sim -- --runs 60 --seed 42 --class mage  # кількість, seed, один клас
npm run probe                       # на якій хвилі гине бот (один візит у Тихий гай з 1-го рівня)
npm run probe -- --endless --level 10  # нескінченний режим: як глибоко заходить герой 10 рівня
```

**Вікі** — `wiki.html` поруч із грою (у dev: `http://localhost:5173/wiki.html`; на сайті — `…/Expedition/wiki.html`; кнопка «Вікі гри» у вікні «Як грати» та на паузі). Сторінка будується з `src/data`: класи, скіли з рангами, пасивки, гілки, вороги, боси й мінібоси з атаками, локації з мобами й механіками, міста й розмови NPC, речі й шанси луту, зілля, хвилі, погода, формули та всі групи `balance.ts` з коментарями. **У `npm run dev` числа й тексти можна міняти прямо у вікі** (назви міст, локацій, ворогів, скілів, описи, репліки NPC): підкреслене — клік, нове значення, `Enter` (`Shift+Enter` — новий рядок у довгому тексті, `Esc` — скасувати). Dev-сервер (`scripts/wikiPlugin.ts`) знаходить значення як літерал у `src/data/*.ts` (`src/wiki/literal.ts`) і переписує файл, зберігаючи лапки й екрануючи їх; сторінка й гра перезавантажуються. Обчислені значення (`1 / 60`, спред, шаблони з `${…}`) не редагуються. Спільні репліки NPC («Бувай.», «Торговець») — у `NPC_LINES` (`src/data/npcs.ts`): правка змінює їх у всіх. Імена в текстах — посилання (`{town:capital}`, `{npc:capitalGuard}`, `{boss:enat:acc}` — `src/data/names.ts`): перейменування у вікі змінює їх у всіх репліках, квестах і лорі; відмінки (`forms`) правляться поруч із назвою. Лор — `src/data/lore.ts`, квести — `src/data/quests.ts`, трофеї й замовлення скупника — `src/data/trophies.ts`. Новий розділ або поле даних — у `src/wiki/sections.ts` / `src/wiki/story.ts` (`v(число, [ГРУПА, ...шлях], формат)`, `t(текст, [ГРУПА, ...шлях])`).

Seed пригоди видно в дебаг-панелі (`` ` `` у dev). Задати його можна через URL: `http://localhost:5173/?seed=123`.

## Деплой (GitHub Pages)

Кожен пуш у `main` запускає `.github/workflows/deploy.yml`: `npm ci` → typecheck → тести → `npm run build` → публікація `dist/` на GitHub Pages. Гра доступна за адресою `https://yuk1teru.github.io/Expedition/` (можна додавати `?seed=123`). Відносні шляхи в збірці задає `vite.config.ts` (`base: './'`). Одноразово в репозиторії треба увімкнути **Settings → Pages → Source: GitHub Actions**. Дебаг-панель у публічній збірці вимкнена.

## Світ

- **Фіксований світ** (PLAN.md 8.1, `src/data/world.ts`): без випадкової генерації. Столиця **Златоград** у центрі; на захід — Прибережна дорога до порту **Чайкова Гавань**; на південь — **Ліс** (місто Смерекове, бос Старий Енат); зі Смерекового на схід через перехідну зону Мокролісся — **Болото** (Очеретянка, Отруйна Мати); на південь через Сухе узлісся — **Пустеля** (Барханськ, Піщаний Хробак); на північ через Передгір’я й Гірський перевал (мінібос Морозний вартовий) — **Крига** (Сніжногір’я, Крижаний Лицар), не з’єднана з іншими біомами. Кожна локація має власний tier, ворогів, мінібоса й механіки (пастки, події, погода, трави); перехідні зони — своїх мобів. Рекомендований рівень = round(tier × 3); кожен переможений бос додає загрозу решті світу. Повний список — у вікі («Світ і локації»).
- **Міста** (8.4): у кожному біомі — своє місто на шляху до боса. Місто — окрема сцена: герой ходить (`WASD` / клік), говорить з NPC (`E` / клік), виходить через браму. Прихід у місто — відпочинок і збереження; саме сюди повертає смерть.
- Карту можна **зумити коліщатком** (від 25% до 160%, навколо курсора) і **тягнути мишею**; кнопки + / − / «Герой».
- Ходити — у сусідні локації (вхід = бій). Пройдену локацію можна «Пройти без бою» або пройти ще раз (продовжити з наступної хвилі чи з 1-ї). У місто останнього відпочинку можна повернутися з будь-якого місця карти.
- **Пустеля**: Скорпіон (жало отруює на 2 с), Кактус (колючки віялом у 3 напрямки), Скарабей (гинучи, розпадається на 2 малих); мінібос — Королівський скорпіон (отруйне жало-ривок, удар хвостом, кличе скорпіонів); бос — **Піщаний Хробак**: зарививається (недосяжний) і виринає під героєм, плює кислотою — калюжі на 3 с; фаза 2 — піщана буря (−30% руху на 4 с), зарививається частіше.
- **Болото**: Слизень (ділиться на двох менших), Жаба (стрибок здалеку), Болотяник (удар сповільнює на 30%); мінібос — Стара Жаба (стрибок, язик-лінія, що притягує героя, кличе жаб); бос — **Отруйна Мати**: отруйні калюжі дугою (6 с), кличе слизнів; фаза 2 — токсична хвиля, кільце від боса, від якого не втекти пішки — лише скілом руху (Ривок, Телепорт, Відскок, черевики) або невразливістю.
- **Крига**: Крижаний вовк (стрибок, укус сповільнює на 35%), Сніговик (сніжки сповільнюють), Крижаний голем (+20 броні); мінібос — Морозний вартовий (крижані шипи під героєм, віяло уламків, кільце холоду); бос — **Крижаний Лицар**: таран по лінії до стіни (1 с телеграф), кільце шипів із двома проходами; фаза 2 — аура холоду (−25% руху поруч), два тарани поспіль.
- Декор арен: дерева й кущі (Ліс), кактуси (Пустеля), очерет (Болото), крижані кристали (Крига).
- Перемога над босом — великий досвід, золото, речі й **додатковий вибір картки** («Нагорода за боса»); переможений бос позначений на карті, «Боси: N/4» у верхній панелі. Після 4-го — екран перемоги.

## Що є у зрізі

- Місто: кожен візит — автоматичний відпочинок (повне лікування + чекпоінт); спорядження, торговець; карта з 3 вузлів: Місто, «Тихий гай», «Лігво Старого Ената».
- Гай стає складнішим з кожним проходженням: `tier = 1 + 0.5 × проходження`, максимум 3. У боса фіксований tier 2.5 (рек. рівень 8).
- Біом Ліс, у кожного ворога одна помітна риса: Вовк — припадає до землі (видно пунктир стрибка) і стрибає, укус сповільнює на 30%; Гриб-плювака — світиться перед пострілом, кожен 3-й постріл — віяло з 3 спор (світіння більше й рожеве); Пеньок — тупотить: червоне коло навколо себе, з якого треба вийти. Елітна версія з аурою.
- Пастки (з 4-ї хвилі): сталеві капкани на арені, з кожною хвилею їх більшає (до 7). Капкан тримає героя 1.1 с (ні руху, ні Ривка) і ранить. Ривок їх перестрибує.
- Події кожної 5-ї хвилі по черзі: погода (Гроза — блискавки під героєм з телеграфом; Туман — видно лише поруч; Злива — −25% руху, −15% швидкості атаки) до кінця хвилі, або Дух бурі — крихкий снайпер, що тримається далеко, стріляє віялом швидких снарядів, які лише сповільнюють (без шкоди), і раз на 30 с відстрибує з поривом вітру, коли герой поруч.
- Локація: хвилі йдуть без кінця, кожна сильніша за попередню — окремо HP (1 + 0.07·i + 0.03·i²), шкода (1 + 0.13·i + 0.018·i²), швидкість (+2.5% за хвилю, до ×1.5), досвід (1 + 0.05·i + 0.025·i²) і золото (лінійно: 1 + 0.06·i); таблиця — нижче. Швидкі й дальні вороги отримують лише 60% приросту HP, танки — 115%. Після 3-ї хвилі ворогів більшає на 1 щоразу, але не більше 28. Кожна 3-тя хвиля приводить мінібоса «Ватажок зграї» (ривок по лінії, стрибок на героя, виклик вовків; зрідка ривок і стрибок ідуть комбо одне за одним — «Комбо!»: 20% / 15%), посиленого так само. Після кожної 3-ї хвилі на краю арени відкривається портал на 15 с — зайшли (кнопка «Увійти» або `E`) — нагорода; інші перерви — 5 с. Будь-яку перерву можна пропустити (`N`). Бос і мінібос виділені колом на землі й мають над собою ім'я та смугу HP.
- Повторний вхід у локацію, яку вже проходили: вибір «Продовжити з хвилі N+1» (з тією ж силою хвиль, до порталу знову 3 хвилі) або «Почати з 1-ї хвилі». На екрані нагороди — обов'язкові хвилі й скільки пройдено (з якої по яку).
- Черевики дають +10–13% швидкості руху (× сила рідкості); зелені й кращі — ривок на `Shift` у напрямку руху: 70 / 95 / 120 / 150 px, перезарядка 15 / 14 / 13 / 12 с (незвичайні → легендарні), слот «Shift» поруч зі слотами Z / X / C.
- Спорядження: зброя, капелюх, броня, черевики. 5 рідкостей (Звичайна, Незвичайна, Рідкісна, Епічна, Легендарна) — сильніші й з більшою кількістю характеристик. По 5 типів предмета на слот (меч, сокира, булава, кинджал, спис…), кожна річ має унікальний вигляд: форма типу + колір рідкості + власний акцент і самоцвіт. Мінібос дає 1 річ (звичайна або зелена), бос — 2 (будь-якої рідкості, здебільшого звичайні; легендарна ≈ 3.5%). Кожна річ має **рівень предмета** (1–300), прив'язаний до біому локації: у лісі — 5–40; мінібос дає нижчі рівні, що ростуть з хвилею, бос — 35–40, торговець — середину діапазону найдальшого пройденого біому.
- Речі падають нерозпізнаними («???») у сумку; щоб вдягнути, треба використати «Лупу» (купується в торговця, можна використати і в бою через інвентар). Поки є непереглянуті речі, блимає «Нова річ — Tab». Торговець купує речі (ціна за рідкістю, нерозпізнані — за пів ціни).
- Рослинки: на початку кожної 2-ї хвилі на арені може вирости рослинка (не більше 2): трава трьох кольорів — зелена (4% макс. HP + 8 HP за 4 с), червона (7% + 15), біла (11% + 25), до 3 кожної, переносяться між боями; на арені одночасно не більше 2 рослинок, і вони ростуть, навіть якщо кишені повні (тоді чекають, поки їх підберуть); «Ягода люті» — +30% швидкості атаки на 8 с. Зілля продає торговець: мале (15% + 10 HP за 3 с, 20 зол.), звичайне (25% + 15, 45 зол.), велике (40% + 20, 90 зол.). Усе лікує поступово (і під ударами); між двома лікуваннями — 1 с. Трава й зілля використовуються зі швидких слотів `Z` / `X` / `C`: нова — сама стає на вільний слот, решту гравець розставляє в інвентарі.
- Герой відновлює 2 HP/с у бою, але лише якщо 1.5 с не отримував шкоди (реген не перекриває шкоду в сутичці); вампіризм лікує і від скілів (зелені цифри раз на пів секунди). Інвентар (`Tab`): фігура людини з речами на голові, тілі, в руці й на ногах, сумка іконками, клік — вдягнути/зняти.
- Візуал атаки: серп удару по дузі, ривок тіла героя вперед, біле кільце на цілі; кільце навколо героя заповнюється до наступного удару (золоте й пульсує, коли атака готова); швидкість атаки — в HUD.
- Автоатака залежить від класу (`basicAttack` у `src/data/classes.ts`): новачок б'є одного ворога у вузькій дузі 50°, Воїн — дугою 140°, ціль отримує повну шкоду, інші в дузі — 40% (сірі цифри). Для Мага й Лучника атака лише описана.
- HUD: HP — смуга з числом під героєм; рівень і смуга досвіду — внизу біля скілів; згори — клас і характеристики, хвиля/HP боса, золото й день. Керування — у вікні «Як грати» на старті та на екрані паузи.
- Смерть не закінчує забіг: герой повертається в місто зі станом останнього візиту туди. Перемога над босом сама зберігає чекпоінт; після екрана перемоги можна продовжити експедицію. Завершити забіг можна з паузи.
- Ручний рух (`WASD`), наведення Ривка й Удару об землю мишею, перестановка скілів перетягуванням.
- Рівні 1–20: на 1–2 лише автоприріст (+15 HP, +2 атаки), на 3-му вибір класу (Воїн, Маг або Лучник; у вікні видно всі скіли класу з рангами і пасивки з максимумом стаків), на 4–12 і 14–20 — вибір з 3 карток, на 13-му — підвищення класу (гілка). Картки й вибір класу перші 1.5 с не реагують на клавіші (смужка «вибір через …»), щоб натискання скілів не обрало картку випадково.
- Воїн: 8 скілів — Вихор, Ривок, Бойовий клич, Удар об землю, Кидок сокири, Залізна шкіра, Землетрус, Гак (ранги 1–5: 2 і 4 — числа, 3 і 5 — особливі модифікатори; підказка будь-де показує всі ранги — ✓ взяті, ▸ наступний). Після вибору класу гравець сам обирає 3 з 8, 4-й приходить карткою. Описи скілів кажуть, від чого рахується шкода (% атаки героя) і яка перезарядка. Пасивки: Броня, Вампіризм (5% за стак), Бойовий азарт (кожне вбивство −0.15 с перезарядки всіх скілів за стак).
- Підвищення на 13-му рівні — одна з двох гілок класу: пасивна механіка, фірмовий скіл (5 рангів, окремий слот `R`) і дві пасивки гілки; далі картки гілки випадають удвічі частіше. Воїн → **Берсерк** (+1% шкоди за 1% втраченого HP, до +60%; Лють — швидкість атаки й вампіризм) або **Паладин** (бар’єр 15% HP кожні 10 с; Священний щит — невразливість і лікування). Маг → **Піромант** (вогняні скіли й снаряд підпалюють; Метеор) або **Кріомант** (заморожені +50% шкоди, розлітаються уламками; Хуртовина навколо героя). Лучник → **Снайпер** (+15% криту, стріли пробивають ще 2; Прицільний постріл крізь усю арену після наведення) або **Звіролов** (вовк-компаньйон, що повертається через 10 с; Поклик зграї — ще 3–4 вовки). Титул («Лучник → Снайпер») і колір обведення героя змінюються.
- **Риси класів**: Воїн (HP ×1.0) відновлює 0.2% макс. HP за секунду навіть посеред бою; Маг (HP ×0.8) має ману (100 + 12 за рівень) — **щит мани** приймає удари раніше за HP (1 мана = 2 HP), кожне вбивство дає +3 мани, а з ворогів (лише для Мага) з шансом 35% випадають **кульки мани** (+10, наступити; зникають за 10 с); у місті мана повна. Лучник (HP ×1.15) прудкий: +20% швидкості руху і 50% шанс ухилитися від удару ближнього бою (снаряди й телеграфи — ні).
- Маг (шкода скілів ×1.25, дальність 260): автоатака — вогняний снаряд у бік курсора, вороги поруч з ціллю отримують 35%. Скіли: Вогняна куля (вибух у точці курсора; палаюче коло, відкидання), Крижане кільце (заморожує навколо; крижане поле), Ланцюгова блискавка (від ворога біля курсора між 4–7 ворогами), Телепорт (до курсора, невразливість; вибух у точці старту), Магічні стріли (самонавідні), Крижаний бар’єр (щит у % макс. HP; холодна хвиля, коли розбивається; заморожує тих, хто б’є впритул), Стіна вогню (упоперек напрямку до курсора; горіння, сповільнення), Вирва (затягує ворогів; вибух наприкінці). Пасивки: Сила чар (+10% шкоди скілів), Зосередження (−6% перезарядки), Магічний бар’єр (+10% HP).
- Лучник (швидкість атаки ×1.4, дальність 300): автоатака — стріла прошиває першого ворога (той, хто позаду, — 60%). Скіли: Мультипостріл (віяло 5–9 стріл), Пастка (біля курсора, до 3–4 одночасно, вибухає під ворогом), Дощ стріл (зона в точці курсора), Відскок (стрибок від курсора й постріл у його бік), Пронизлива стріла (крізь усіх на лінії; мітить, росте з кожним пробитим), Мітка мисливця (+30–40% шкоди по цілі), Сітка (зв’язує ворогів у точці), Шквал (+150–200% швидкості атаки). Пасивки: Влучність (+4% криту), Спритність (+8% швидкості атаки), Пробиття (+1 ворог для стріл, до 3).
- Картки: можна «Перекинути» за золото (20, далі +15 за кожне перекидання) або «Пропустити» — золото (10 + 3 × рівень) і баф на 12 с: +5 HP/с, +20% шкоди, +20% швидкості руху (поза боєм — з наступним боєм).
- Бос Старий Енат: коріння (телеграфи під героєм), призов вовків, удар навколо себе; друга фаза на 50% HP.
- Екрани нагороди, смерті й перемоги; «соковитість»: цифри шкоди (криты більші й жовті), білий спалах при влучанні, частинки, тряска (вимикається при `prefers-reduced-motion`), хіт-стоп, кільце нового рівня, «+N золота», поява ворогів зі зростанням.
- Симуляція балансу `npm run sim`: повні забіги ботом (`scripts/route.ts`), звіт — перемоги загалом і по класах, рівень на кожному босі, смерті за глибиною, дні до перемоги, тривалість боїв.

Реалізація — функція `SkillImpl` у `src/systems/skills/<клас>.ts` (повертає `false`, якщо немає цілі — тоді перезарядка не витрачається), додайте її в об’єкт класу й, за потреби, новий `SkillIcon` у `src/render/icons.ts` / `classIcons.ts` та ефекти в `src/render/skillFx.ts`. Щоб скіл випадав у картках — додайте id у `skills` класу (`src/data/classes.ts`).

## Рішення прототипу

1. **Топологія зрізу.** Обидві локації з'єднані з Містом (2 ребра), тому лігво боса доступне з самого початку, а між боями завжди можна зайти в місто. Вхід у локацію завжди запускає бій; клік по поточній локації — повторне проходження без лікування.
2. **Ядро без DOM.** `GameLoop` отримує планувальник кадрів (`requestAnimationFrame`) ззовні, `bindInput` — джерела подій, `ScreenManager` узагальнений за типом контексту рендеру. Тільки `main.ts` і `src/render` торкаються `window`.
3. **Досвід і золото — за кожне вбивство**, бонус золота — за зачистку. Підвищення рівня посеред бою ставить гру на паузу і відкриває вибір (клас / картка). Черга виборів зберігається в `GameState.modalQueue`, тому кілька рівнів поспіль обробляються по черзі.
4. **Масштабування досвіду**: досвід ворога росте з tier так само, як HP (+45% за tier). Штраф досвіду (25%, якщо герой на 4+ рівні вище рекомендованого) реалізовано, хоч у зрізі він майже не спрацьовує.
5. **Посилення ворогів від днів** реалізоване формулою, але вимкнене в зрізі (`SCALING.dayThreat.enabled = false`). Лічильник днів росте.
6. **Бойовий клич, ранг 3** «+20% броні»: у героя базова броня 0, тому трактується як −20% отриманої шкоди на час дії (видно як сталевий шестикутник навколо героя). **Провокація** змушує стрільців припинити тримати дистанцію і підійти впритул — вигідно для Воїна.
7. **Ривок** дає невразливість на час стрибка; якщо на арені є телеграфи боса, точка приземлення шукається поза ними (біля тієї ж групи) — так від коріння можна втекти Ривком.
8. **«Немає цілі»**: Вихор вимагає ворога в радіусі 150 px, Ривок — групи в межах 300 px, Удар об землю — ворога в конусі, Бойовий клич — будь-якого живого ворога. Інакше кулдаун не витрачається, слот спалахує червоним.
9. **Ранг 3** = значення рангу 2 (+30% шкоди, −10% кулдауну) + модифікатор.
10. **Стрільці** відступають повільніше, ніж ходять (40% швидкості), інакше ближній бій перетворювався на погоню.
11. **Коріння Ената**: одне коло завжди під героєм, решта — на відстані 80+ px, щоб не накладатися на героя кількома колами одразу.
12. **Призвані ворогами** боса дають досвід, але не золото; зі смертю боса гинуть і вони. Після перемоги над босом (єдиним у зрізі) одразу показується екран перемоги.
13. **Хіт-стоп** реалізований у рендері (пропуск кроків симуляції), тож на симуляцію балансу не впливає.
14. **Числа рендеру**: геймплейне «відчуття» (тривалості, тряска, кількість частинок) — у `src/data/fx.ts`; координати розкладки UI й кольори інтерфейсу лишаються в `src/render`.
15. **Пропозиція карток**: якщо валідних карток менше трьох, пропонується менше; якщо жодної — вибір пропускається.
16. Версії інструментів на момент створення: TypeScript 7, Vite 8, Vitest 5, tsx 4.

Після першого плейтесту (етап G у SLICE.md) кілька рішень SPEC.md змінено на прохання гравця:

17. **Ручний рух і атака за мишею.** SPEC описує повністю автоматичний рух; тепер герой гравця ходить лише від `WASD`/стрілок, а автоатака б'є найближчого ворога в дузі 120° в бік курсора (дальній бій — стріляє вздовж прицілу, якщо в конусі 50° є ворог). Курсор поза ареною — атака триває в останньому напрямку. Від коріння боса й снарядів можна відбігти; стрілець світиться 0.6 с перед пострілом, снаряд летить туди, де був герой. Автохід до ворогів лишився тільки в бота симуляції (`input.control = 'bot'`), тож симуляція оцінює баланс для «ідеально автоматичного» героя, а не для живого гравця.
18. **Наведення мишею** для скілів з напрямком (`aimable` у даних): Ривок летить до курсора (до своєї дальності) і тоді не потребує цілі; Удар об землю б'є конусом до курсора, якщо на арені є вороги. Курсор поза ареною (наприклад, клік по слоту) — автонаведення.
19. **Перестановка скілів** — перетягування в панелі; слоти без «дірок»: перетягування на порожній слот ставить скіл останнім.
20. **Портал замість автоматичного кінця бою.** Вихід з локації — лише крок у портал, і лише під ручним керуванням (або коли на полі нікого): автобій не виносить героя в портал випадково. Додаткові хвилі стартують через 5 с після попередньої. Нагорода (бонус золота, +1 до складності гаю, +1 день) — при виході.
21. **Мінібоси** використовують ту саму систему, що й боси (таблиця атак, телеграфи), плюс контактний удар і ривок по лінії; фаза 2 для них не обов'язкова.
22. **Чекпоінт** знімається на старті забігу і при кожному потраплянні в місто (окремої кнопки «Відпочити» немає — відпочинок автоматичний). Смерть відновлює героя (рівень, клас, скіли, речі), золото, день і прогрес карти з чекпоінта; статистика забігу (вбивства, шкода, час, смерті) зберігається. Таймер гри стоїть на екранах смерті й перемоги. Кнопка «Новий забіг» лишилась на екрані смерті як опція.
23. **Речі**: рідкість визначає силу (звичайна — тільки основна характеристика, епічна — сильніша основна + додаткова). Рівня речі поки немає.

Після другого плейтесту (етап H):

24. **Слоти скілів** — кожен скіл пам'ятає свій слот (`HeroSkill.slot`), тож слоти можуть бути з пропусками; новий скіл займає перший вільний слот.
25. **HP боса/мінібоса** — лише у верхній панелі HUD (центральний блок), арена нічим не перекрита.
26. **Виправлено баг**: ШІ звичайних ворогів обнуляв швидкість босам, тому Енат стояв на місці, а Ватажок «зависав» після першого ривку. Тепер обидва ходять; баланс перераховано.
27. **Портал** відкривається на краю арени (34 px від краю), подалі від героя; вхід — тільки кнопкою «Увійти в портал» або `E`, коли герой у межах 40 px. Ні рух, ні штовхання ворогів у портал не затягують.
28. **Ривок** при наведенні летить точно до курсора (до 300 px) і б'є всіх ворогів на шляху (смуга 56 px) та навколо точки приземлення — кожного один раз.
29. **Інвентар** — модальне вікно (пауза), а не окремий екран.

Етап I:

30. **Автоатака класу — дані, а не код героя**: `BasicAttackDef` (`melee`: дуга + частка сплешу; `ranged`: поки лише опис). Новачок і Воїн реалізовані; Маг (снаряд + опік впритул) і Лучник (прострілювання) описані у вікні вибору класу. Бот симуляції б'є так само (зі сплешем), тому баланс перераховано.
31. **Сплеш** не робить окремого кидка криту: інші цілі отримують 40% від уже кинутої шкоди основної цілі (і крит, якщо він випав).
32. **«Як грати»** показується один раз при запуску гри; той самий список керування — на екрані паузи.

Етап J:

33. **Тряска на паузі** — баг: поки відкрите вікно вибору картки чи пауза, таймер тряски стояв, а зсув рахувався щокадру. Тепер на паузі зсуву немає, ефекти (портал, банери) догравають після вибору.
34. **Портал** активний лише в перерві між хвилями; під час хвилі він тьмяний і не працює. Перерва між додатковими хвилями — 10 с (було 5), щоб встигнути дійти до краю арени.
35. **Перемога над босом** зберігає чекпоінт (смерть після неї не відкочує перемогу) і показує екран перемоги лише першого разу (`runCompleted`); далі — звичайний екран нагороди. «Продовжити експедицію» повертає на карту з усім прогресом.
36. **Речі** лише в сумку з позначкою «НОВЕ»; позначки знімаються, коли закрити інвентар. Бот симуляції вдягає речі в порожні слоти — як зробив би гравець, тому баланс не змінився.
37. **«Завершити забіг (поразка)»** на паузі потребує другого кліку протягом 3 с; незавершений бій зараховується в статистику, далі — екран «Забіг завершено» і «Новий забіг». Час гри стоїть на екранах смерті, перемоги й завершення.

Етап K:

38. **Вампіризм** і раніше працював від усіх джерел шкоди, крім шипів, але лікування не показувалось. Тепер воно сумується й показується зеленою цифрою раз на 0.5 с; регенерація 1 HP/с цифр не показує.
39. **Броня**: формула м'якша (`k = 200`: 50 броні — −20%, 100 — −33%), пасивка «Броня» +6 за стак (було +8), броня в речах — 4–6 × сила рідкості.
40. **Розпізнавання**: нерозпізнану річ видно як «???» з силуетом типу й кольором рідкості; її можна продати за пів ціни. Лупа витрачається на одну річ.
41. **Вдягання** — тільки перетягуванням на фігуру/слот або через ПКМ-меню; простий клік лише підказує, як це зробити. Перетягнута у сумку вдягнута річ знімається.
42. **Рослинки** з'являються на початку парних хвиль (бонусні теж), у випадковому місці не ближче 120 px до героя; виростають за 2 с, після чого їх можна підняти, зайшовши на них. На арені — не більше 2 одночасно; якщо такої трави вже 3, нова лишається рости, доки місце не звільниться. Бот симуляції рослинки не збирає, але їсть траву нижче 40% HP.
43. **Бот і речі**: після кожного бою купує лупи на нерозпізнані речі (якщо вистачає золота), розпізнає й вдягає в порожні слоти.

Етап M:

44. **Ріст хвиль** — квадратичний: ранні хвилі майже як раніше, далі сила росте все швидше. Кількість ворогів росте лише після першого порталу, щоб перший гай лишався прохідним для новачка.
45. **Портал** розміщується один раз (на краю арени) і відкривається після кожної 3-ї хвилі на 15 с; кожне відкриття — банер «Портал відкрито на 15 с!». У верхньому HUD видно, через скільки хвиль буде портал.
46. **Мінібос** — кожна 3-тя хвиля, його HP/шкода/досвід/золото множаться на силу хвилі; удар-ривок 3 → 4, ближній удар ×1.3, телеграф 0.8 → 0.7 с.
47. **Скіли класу**: пул — 8 скілів; старт — 3 на вибір гравця (бот бере Вихор, Ривок, Удар об землю), 4-й слот заповнюється карткою «Новий скіл» з решти 5. Ранг 1 обраних скілів.
48. **Пропуск картки** дає баф з полями `damageMult`, `moveSpeedMult`, `regen`; ці поля враховують і автоатака, і скіли (через `heroAttack`), і регенерація.

Після плейтесту етапу M (етап N):

49. **Ранги 1–5** замість 1–3: кожен скіл у даних має параметри рангу 1 і 4 покращення з абсолютними значеннями (`upgrades`); ранги 3 і 5 — особливі модифікатори з текстом, числові зміни описуються автоматично («шкода 60% → 72%»). Максимальний рівень піднято до 15 (12 карток), бо прокачати 4 скіли до 5 рангу за 7 карток неможливо.
50. **Затримка карток** 1.5 с (`CARDS.inputDelay`) — і для вибору класу; кнопки «Перекинути»/«Пропустити» теж чекають.
51. **Гак** оглушає підтягнутих уже з 1-го рангу (0.8 с), тож швидкі вороги не кусають одразу після притягування.
52. **Землетрус**: радіус 160 → 110, сповільнення 40% → 25% (0.8 с), шкода 90% → 60%; оглушення лише на 5-му рангу (0.3 с). **Ривок**: дальність 300 → 240, оглушення 1 → 0.6 с, перезарядка 7 → 8 с (дальність і оглушення ростуть на 4-му рангу).
53. **Проти кайту**: вороги швидшають з кожною хвилею, укус вовка сповільнює, капкани з 4-ї хвилі (Ривок під час капкана заблоковано — «Пастка!»), Злива сповільнює. Залізна шкіра 5-го рангу знімає й не пускає сповільнення/капкани/оглушення.
54. **Сила хвиль** розділена: HP росте круто (пізні хвилі довші), шкода — майже лінійно (між сусідніми хвилями не більше +16%), розмір хвилі обмежено 28 ворогами. Різкий «ваншот» на 13-й хвилі давав натовп: 33 вороги, кожен вовк б'є на 11.6, і всі доходять до героя за секунду. Тепер ворогів ≤ 23 на 13-й хвилі, а найсильніші удари (тупотіння, стрибок вовка, блискавка) мають телеграф.
55. **Реген** 1 → 2 HP/с, але тільки після 1.5 с без шкоди: у сутичці він не перекриває вхідну шкоду, а між сутичками лікує швидше. Базова шкода ворогів 1.6/1.6/2.6 → 1.8/1.8/3.
56. **Повернення з карти**: Місто завжди доступне (клік, кнопка, `Esc`), навіть якщо герой уже «стоїть» у місті.
57. **Продовження локації**: вузол пам'ятає `lastWave` — скільки хвиль пройдено за останній успішний вихід; продовження стартує з тієї ж сили (і тим самим tier гаю), обов'язкові — наступні 3 хвилі.
58. **Трава** не росте, якщо в сумці вже максимум (3) з урахуванням тієї, що вже росте; замість неї може вирости ягода.
59. **Бот симуляції** виходить з червоних кіл телеграфів (у бік від центру) — інакше тупотіння пеньків, яке гравець легко обходить, вбивало б бота. Через це бос став легшим для бота — Енату підняли шкоду.

Етап O:

60. **Залізна шкіра** — стійка, а не миттєвий щит: 6 с (8 с на 4-му рангу), −35% вхідної шкоди (−45% з 2-го рангу) і лікування 20% / 30% макс. HP протягом дії (через `regen` бафу, працює навіть під ударами). 3-й ранг: +25% шкоди героя на час дії — скіл для атаки, а не для «танкування»; 5-й — несприйнятливість до контролю.
61. **Трава** лікує 10% (було 25%): ресурс на крайній випадок, а не друге життя.
62. **Гак** більше не штовхає імпульсом (важкий пеньок пролітав 25 px): вороги летять по прямій зі швидкістю 1800 px/с до місця впритул до героя, незалежно від маси. Боса не висмикує — лише б'є й оглушує.
63. **Золото** рідкісне: 0.4 × tier за ворога, росте лише лінійно з хвилею (×1.54 на 10-й), дробові частини накопичуються між вбивствами. Мінібос 8, Дух бурі 12, Енат 100, бонус зачистки 10 × tier, пропуск картки 5 + рівень, ціни продажу речей удвічі нижчі. Перший гай дає ≈ 35 золота (≈ одна лупа), 15 хвиль — ≈ 250–300 (раніше гравці мали 6–10 тис.).
64. **Шипи прибрано**: «танкування» в грі не цікаве, а шипи ні з чим не поєднувались. Замість них — «Бойовий азарт»: вбивства скорочують перезарядку скілів; поєднується з Вихором/Землетрусом (багато вбивств) і Вампіризмом (більше скілів — більше лікування). Механіка шипів (`thorns`) лишилась у коді для інших класів.
65. **Складність понад бота**: гравець ухиляється й кайтить значно краще за бота, тому після налаштування по симуляції шкоду й HP хвиль додатково підняли (бот гине частіше, ніж у цілях зрізу, — це навмисно).

Етап P:

66. **Дальність удару = намальований клин**: дальність класу рахується від краю героя (40 px), а не від центру; ворог отримує удар, якщо хоч частково в клині. Раніше клин малювався на 54 px від центру, а бив на 40.
67. **Ривок мінібоса** має ліміт часу (відстань / швидкість + 0.25 с) і точку, притиснуту до арени: коли герой тілом або стіною блокує стрибок, Ватажок зупиняється, а не «застрягає» назавжди.
68. **Скіли з курсором над HUD**: напрямок — до курсора, притиснутого до краю арени (раніше — автонаведення, через яке Ривок писав «Немає цілі»). Бот курсора не має й наводиться автоматично.
69. **Ривок черевиків** — коротка невразливість на час польоту (~0.1 с), напрям героя не змінює (атака триває туди, куди цілиться гравець), блокується пасткою й оглушенням.

70. **Торговець** розпізнає, вдягає й продає обрану річ прямо у своєму вікні; `Tab` (або «Спорядження») відкриває інвентар поверх торговця, після закриття — назад до торговця.
71. **Комбо Ватажка** рідше: ривок → стрибок 40% → 20%, стрибок → ривок 35% → 15%.

72. **Лікування** — набір предметів з відсотком і фіксованою частиною (`heal: { pct, flat, duration }`): трава слабша й лише з арени, зілля сильніше й лише в торговця. Лікування йде через баф `regen`, тому працює під ударами, а різні предмети складаються. Спільна перерва 1 с не дає випити все за мить. Клавішу `G` замінили три слоти `Z` / `X` / `C`. Бот п'є найсильніше з того, що має, нижче 40% HP.

73. **Характеристики речей**: звичайна — 1, зелена й синя — 2, епічна — 3, легендарна — 4 (у кожного слота 3 додаткові, легендарна має їх усі).
74. **Покупка речі** в торговця: обирається слот, рідкість випадкова (зелена 60%, синя 30%, епічна 10%, легендарних і звичайних немає), річ одразу розпізнана й лягає в сумку. Ціна 120 — кілька проходжень гаю.
75. **Ривок черевиків** — у напрямку руху (`WASD`), а не до курсора: так ним ухиляються, не відводячи прицілу.

76. **Продаж** — через випадаюче меню на речі (у торговця — лівий клік, в інвентарі поверх торговця — ПКМ), без окремого рядка кнопок.

77. **«Що нового»**: остання побачена версія зберігається в `localStorage` браузера (лише в `main.ts`; логіка порівняння — `src/core/version.ts`). Хто грав до появи списку (версія не збережена), бачить усі оновлення після 0.1.0 — задеплоєної версії етапу M. Якщо сховище недоступне (приватний режим), вікно показується при кожному запуску. Вікно відкривається поверх «Як грати», по одному оновленню на сторінку (`←` / `→`).

78. **Пропуск перерви** не карає за поспіх: пропущений час зараховується перезарядкам (скіли, ривок черевиків), бо інакше вигідніше просто чекати.
79. **Ефект лікування**: поки діє трава чи зілля, навколо героя аура й хрестики кольору предмета (зелена / червона / біла трава, кольори зіль); при використанні — кільце, частинки й напис з назвою.

80. **Чекпоінт і при виході з міста** (`leaveTown`): усе, що зроблено в місті (лупи, покупки, продаж, перевдягання), не відкочується смертю.
81. **Рідкості**: сила зеленої 1.35 → 1.3, синьої 1.75 → 1.9 (синя має стільки ж характеристик, скільки зелена, тож відрізняється силою). Шанси: мінібос — звичайна 42%, зелена 35%, синя 21%, епічна 2%; торговець — зелена 65%, синя 30%, епічна 5%; бос (2 речі) — синя 45%, епічна 35%, легендарна 20%. Легендарні — лише з боса.
82. **Підказка речі**: назва кольором рідкості; для речі в сумці — порівняння з одягненою в тому ж слоті (кожна характеристика, що зміниться: зелена — краще, червона — гірше; для черевиків — і дальність ривка) або «Слот вільний».
83. **Шанси луту (етап Q)**: ваги рідкостей не мусять давати 100 — бос 70 / 20 / 14 / 7 / 4 (звичайна … легендарна) ≈ 61% / 17% / 12% / 6% / 3.5%; мінібос — звичайна 70 / зелена 20, тобто ніколи не краще за зелену.
84. **Порівняння на `Shift`**: без `Shift` підказка речі коротка (характеристики й рядок «Shift — порівняти з одягненим»); з `Shift` — поруч друга підказка «Одягнено» з річчю того ж слота, а в першій — різниця кожної характеристики (зелена — краще, червона — гірше). Стан клавіші береться з `input.held`, тож працює і в інвентарі, і в торговця.

128. **Кінець героя — мета-збереження окремо від героя** (ROADMAP 9.6): без життів (або «Завершити пригоду» на паузі) збереження героя видаляється, а надгробок іде в `expedition.meta`. Надгробки стоять на кладовищі столиці (ділянки `graves` у планах міста, новіші — першими) і читаються на `E`; рекорди рахуються з надгробків, тож окремо їх не зберігаємо.

129. **Статистика боїв — у мета-збереженні, а не в герої** (ROADMAP 9.7): кожен завершений бій (локація, tier, рівень, клас, результат, час, отримана й завдана шкода, випиті зілля, причина смерті) додається в `expedition.meta` (до 3000 останніх). Так статистика переживає героїв і віддається одним файлом («Статистика боїв» у головному меню); у dev-вікі розділ «Статистика боїв» зводить її по локаціях разом із файлами друзів — баланс видно з живої гри, а не лише з бота.

130. **Рівні замість tier (ROADMAP 10.1–10.2).** Локація в даних має `level` — рівень монстрів на шкалі героя (1–30); формули працюють із силою `tier = 1 + (level − 5) / 6` (`LEVELS`). Щоб не ламати баланс до етапу 15, нова шкала — це стара, розтягнута вдвічі: новий рівень = 2 × старий − 1 і для героя, і для локацій (Тихий гай 5, Енат 14, Крижаний Лицар 26). Тому приріст за рівень удвічі менший (+7,5 HP, +1 атаки), крива досвіду дає той самий темп (`base × (level + 0,5)^1,6`), клас — на 5-му, просування — на 25-му, картка — кожні 2 рівні (до дерева талантів на етапі 12), штраф досвіду — після 6 рівнів переваги. Загроза босів додає рівні (+6 локаціям, +5 босам), але не вище максимального рівня героя. Збереження формату 1 мігрують (рівень × 2 − 1).

131. **Навала замість загрози днів (ROADMAP 10.3).** Шкала 0–100% видна на карті й росте на 1% за день; сила ворогів росте з нею лінійно до +40% на 100% (було +10% кожні 5 днів без стелі — повільніше й передбачуваніше). Пороги 25/50/75/100% — поки лише повідомлення (`src/data/invasion.ts`), події — етапи 15 і 17. Оголошений поріг пам'ятається в збереженні (`invasionSeen`). Швидкість навали (`perDay`) калібруємо разом з тривалістю кампанії (VISION, відкрите питання 1).

132. **Автошлях і переходи (ROADMAP 10.4; заміняє «Пройти без бою» з рішення 87).** Клік по далекій локації шукає найкоротший шлях лише через міста й пройдені локації (`findRoute`, через лігво боса — ніколи). Кожна пройдена локація на шляху — **перехід**: бій однієї хвилі без порталу (`Battle.transit`), що коштує день, але не рахується як зачистка й не збиває збережений прогрес хвиль. Між переходами карта показує маршрут із кнопками «Далі в дорогу» / «Зупинитися»; поразка обриває маршрут. Місто на шляху проходиться без зупинки (без відпочинку). Місто останнього відпочинку, як і раніше, доступне з будь-якого місця безкоштовно.

133. **«Швидка тарадайка» (ROADMAP 10.5).** Візник у кожному місті (NPC з дією `openCoach`) возить лише в міста, до яких герой дійшов пішки (`townsVisited`: відпочинок у місті або місто на автошляху). Ціна рахується з фарму, а не задається вручну: `COACH.share` золота найлегшої локації регіону призначення — тож вона сама піде за балансом золота й рівнів. Поїздка не витрачає днів, тому навала за неї не росте.

134. **Туман війни (ROADMAP 10.6).** Видно відвідані місця (`nodesVisited`), пройдені локації, відвідані міста та їхніх сусідів; дороги — лише між видимими місцями, решта карти під темним шаром з м'якими «просвітами» (полотно в ¼ розміру, кешоване за набором видимих місць). Таємні місця (`secret` у світі) лишаються схованими навіть по сусідству, доки їх не відкриє підказка чи квест (`revealSecret`, етап 16). Вимикач — `noFog` (дебаг, 10.8).

135. **Налаштування й дебаг (ROADMAP 10.7–10.8).** Налаштування гравця (гучність, тряска, цифри шкоди) — окремо від героя (`expedition.settings`, `src/core/settings.ts`); биті значення повертаються до типових. Дебаг-панель (`` ` ``) має вимикачі: туман, тарадайка даром, без навали, нескінченні життя (поруч із безсмертям і вільними переходами). Розділ вікі «Усі налаштування» (усі числа `balance.ts`) — лише в dev.

136. **Квести грають з даних (ROADMAP 11.1–11.2).** Розмова з NPC отримує пункти квестів у коді (`withQuests`): «❗ взяти», «💬 поговорити / віднести», «✔ здати» — тож новий квест — це лише запис у `src/data/quests.ts`. Цілі йдуть по черзі; бій рахує вбивства за видом і мінібосів (`BattleStats.killsById`, `minibossKills`), прибуття рахується в `markVisited`. Квести з цілями, яких гра ще не вміє (принести трофеї — етап 14, особливі), не пропонуються. Нагороди очками таланту, каменями й дарами накопичуються в стані до етапів 12 і 14. Прогрес квестів не відкочується смертю (як знання).
137. **Пролог (ROADMAP 11.3–11.4).** Нова пригода — у Чайковій Гавані: герой прокидається на пристані поруч із рибалкою (`TownLayout.arrival`), Прибережна дорога стала найлегшою локацією (рівень 3). Сим-бот і тести, як і раніше, стартують у столиці (`startPrologue` викликає лише гра). Підказки навчання (`src/data/hints.ts`) показуються раз на гравця (`meta.hintsSeen`), а не на героя.

138. **Інтер'єри — ті самі плани міст, лише малі (ROADMAP 11.6).** Кімната (`INTERIORS`, `room()`) — `TownLayout` зі стилем `interior`: стіни й меблі — блокуючі «будівлі» (`kind: 'wall' | 'furniture'`), «брама» — вихід. Будівля з `interior` має двері посередині нижньої стіни (килимок і ліхтарик): підійшов — зайшов, вийшов — стоїш на сходинці (`doorStep`). Тому вся логіка ходьби, розмов і квестів працює в кімнатах без змін. NPC стоїть або вдома (у `npcs` кімнати), або біля дому (`home` у місті) — розклад за часом доби додамо пізніше. Тести перевіряють, що кожні двері досяжні від брами, а в кожній кімнаті досяжні вихід і всі NPC.
139. **Справжня столиця (ROADMAP 11.7).** Ізяслав зібрано наново: мури з вежами брами, канал з трьома мостами (`bridges` — проміжки у воді), криві вулиці (`streets` — ламані без колізій), площі, ринок і житлові квартали. «Кілька продавців» — це `shop` у торговця (`goods`, `slots`): вікно торговця показує лише його товари. Інші міста перебудуємо за цим зразком на етапі 16.

140. **Стихії через «контекст касту» (ROADMAP 12.2).** На час скіла бій пам'ятає його стихію (`Battle.castElement`): усе, що скіл створює (снаряди, зони, вибухи, фінали зон, відкладені постріли), її успадковує, тож реалізації скілів не довелося переписувати. Базова атака бере стихію героя (стріли лучника; камінь душі — етап 14), підпал — Вогонь. Множник — `elementMultiplier` (`src/data/elements.ts`): таблиця для захисту 1 рівня, ±25% за рівень, стеля 200%; нейтральна шкода по панцирних — лише `shell`. Профілі захисту — окремою таблицею `ENEMY_ELEMENTS`, а не в кожному ворогові: так усі біоми видно й правлять в одному місці вікі.

141. **Дерево талантів замість карток рівня (ROADMAP 12.1–12.7).** Дерево класу — дані (`src/data/talents.ts`): три ряди скілів, пасивок і типів стріл; ряди відкриваються вкладеними очками (5, 10), ціни рангів 1/1/1/2/2 — повне дерево коштує ~2× більше, ніж очок за кампанію. Очки — за рівні (1 з 4-го, +1 кожен 5-й) і квести. Розвилки — у даних скіла (`forks` на рангах 3 і 5); перший варіант — колишній ранг, тож старі герої поводяться як раніше. Параметри скіла рахуються з урахуванням вибраних варіантів (`skillParams(id, rank, forks)`), а стихія розвилки перекриває стихію скіла. Панель: 5 класових слотів і R/F для гілки; вивчений скіл без вільного слота чекає поза панеллю. Картки поки лишаються в коді лише для дарів (12.8). Збереження формату 2 мігрують (скіл гілки зі слота 4 — на R).

142. **Дари — модифікатори з даних, а не код (ROADMAP 12.8).** Кожен дар — список ефектів п'яти видів (`stat`, `tag`, `element`, `status`, `skill`), які рушій уже вміє: характеристики додаються в `recomputeHeroStats`, «скіл отримує особливість раніше» — це мінімальне значення параметра скіла (`giftSkillParams`), шкода міток — множник на час касту (`hero.castMult`), стихій і статусів — у `damageEnemy`. Тому новий дар — це лише запис у `src/data/gifts.ts` (усе редагується у вікі). Картки рівня й модуль карток прибрано; перекидання й пропуск перейшли до дарів.

143. **Спеціалізація у два етапи (ROADMAP 12.6).** Гілка не купується, а приходить з рівнями: на 12-му — перший скіл (R) і механіка, на 22-му — другий скіл (F) і бонус характеристики гілки (`signature2`, `bonus2` у `src/data/promotions.ts`). Ранги скілів гілки й пасивки гілки купуються очками в колонці гілки дерева (`BRANCH_ROW`); вони не відкривають ряди класового дерева. Нові скіли зібрано з наявних механік (зони, снаряди з вибухом і статусом, союзники), тож ведмідь — це той самий союзник, що й вовк, лише більший (`Ally.kind`). Нові розвилки класових скілів на 22-му рівні перенесено на етап 15.6.

144. **Арени з даних (ROADMAP 13.1).** Межі арени тепер свої для кожного бою (`ARENA` — поточна арена, `ARENA_VIEW` — вікно бою на екрані); більшу за екран арену камера прокручує за героєм, а приціл миші переводиться в координати світу. Перешкоди — кола (тіла по них ковзають, тож простого виштовхування вистачає без пошуку шляху), снаряди об них розбиваються. Рельєф: вода сповільнює всіх, колючки ранять лише героя, у траві стрільці не бачать героя здалеку й підходять. Арени — `src/data/arenas.ts`; локація без своєї арени б'ється на рівному полі розміром з екран.
145. **Локація — похід через арени (ROADMAP 13.2).** Замість одного бою з порталом після 3-ї хвилі локація — послідовність арен (`src/data/expedition.ts`, `src/systems/expedition.ts`): вхід (2 хвилі) → розвилка з двох (вівтар дару / скарб із засідкою) → лігво (хвиля з мінібосом і скриня). Короткі регіони (узбережжя, перехідні зони) — вхід і лігво; лігво боса — передпокій і бос. Кожна арена — окремий `Battle`, але HP, ріст хвиль і підсумок (вбивства, досвід, золото, речі) тягнуться через увесь похід; локація пройдена (квести, день, дари за першу зачистку) лише після останньої арени — `completeBattle(..., { final })`. Між аренами вікно «Далі»: нагорода арени, HP, вибір розвилки або повернення на карту без зачистки. Вівтар дає дар раз на локацію (`node.altarUsed` у збереженні). Портал, «продовжити з хвилі N» і нескінченні хвилі прибрано; пройдену локацію можна пройти знову або перетнути однією хвилею.
146. **Цілі арен (ROADMAP 13.3).** Розвилка обирає дві з трьох категорій (вівтар / завдання / скарб); завдання — одна з цілей `src/data/objectives.ts`: **гнізда** (нерухомі «вороги» з `Enemy.nest`, що виводять звірів з розкладу локації, з обмеженням живих; перемога — гнізда зруйновано й виводок добито) і **порятунок** (час у колі біля полоненого; групи звірів з краю). Арена із завданням не має хвиль (`Battle.waves = null`, `Battle.objective`), а її звірі ростуть як наступна хвиля локації. Бот у порятунку тримається біля полоненого. Захист каравану відкладено: він потребує, щоб вороги цілили не лише в героя.
147. **Арени Лісу різні (ROADMAP 13.4).** Кожна локація Лісу має свою арену з 13.1; тепер особливості з їхніх описів працюють: арена може обмежити краї, звідки приходять вороги (`ArenaDef.spawnSides`, Вовча стежка — лише з кінців). Щоб арени одного походу не були однакові, `setupArena` віддзеркалює арену: розвилка — зліва направо, лігво — згори донизу; арени з морем чи струмком унизу (`fixedY`) замість цього дзеркаляться зліва направо. Нових координат не треба — та сама арена дає два-три різні поля.
148. **Процедурний звук (ROADMAP 13.5).** 15 звуків синтезує WebAudio з рецептів у `src/data/sounds.ts` (хвиля, висота з ковзанням, тривалість, гучність, арпеджіо, мінімальний проміжок між повторами) — без аудіофайлів. `eventSound` (`src/render/sound.ts`) перетворює події гри на звуки, `SoundPlayer` грає їх із гучністю з налаштувань; кнопки клацають через `setButtonSound`. Браузер дозволяє звук лише після жесту, тож AudioContext створюється на першому натисканні клавіші чи кліку. Логіка й бот про звук не знають — лише підписка на шину подій у `App`.
149. **Трофеї в грі (ROADMAP 14.1).** Трофеї — лічильники в `hero.trophies` (не речі в сумці, бо їх багато й вони однакові); формат збереження 4 додає порожній набір. Падають у `killEnemy` (`src/systems/trophies.ts`): звичайні — зі свого виду, рідкісні — з мінібосів, трофеї босів — з босів; виведені гніздами й викликані вороги нічого не лишають, щоб гнізда не були фермою. Реліквії — у скрині арени скарбу, за регіоном локації. Торговець купує все однією кнопкою, але лишає те, що збирає квест. Квест «принести» забирає трофеї, щойно їх досить (`questsBring` після кожного бою й при взятті квесту), — так зібране не продасться випадково.
150. **Замовлення скупника (ROADMAP 14.1а).** Ізидор у діалозі відкриває вікно замовлень (`ARTIFACT_ORDERS`, `src/systems/orders.ts`): кожне — набір трофеїв за золото, більше за ціну торговця (тест це перевіряє), один раз (`state.ordersDone` у збереженні). «Де шукати» складається з даних світу (хто дропає трофей і в яких локаціях живе; для реліквій — регіони скарбів). Торговець не продає трофеї, на які чекає відкрите замовлення, — інакше кнопка «продати все» з'їдала б рідкісні реліквії. Замовлення відкриваються після квесту `systemBuyer` (так задумано в даних квестів).
151. **Алхімія (ROADMAP 14.2).** Рецепти — дані (`src/data/alchemy.ts`): частини-трофеї, золото, хто варить і що дає. Зілля йдуть у сумку (до максимуму), Еліксир повернення дає життя (до 5) і відомий лише після квесту лікарки. Еліксир-баф випивається одразу (`hero.elixir`), додає до тієї ж характеристики, що й дари, і тане з кожною завершеною ареною — так його сила прив'язана до походу, а не до секунд. Діалог «Звари мені щось» отримують усі, хто є в `at` рецептів, — новий алхімік додається даними.
152. **Душі й рунічні камені (ROADMAP 14.3).** Вісім душ (`src/data/souls.ts`) — по одній на родину звірів; у кожної стихія (для зброї) і властивість (для іншої речі: характеристика або опір отруті / сповільненню / оглушенню, разом до 80%). Душа — окрема сутність бою (`Battle.souls`), а не підбирання з трав: вона з'являється над убитим, висить кілька секунд і розвіюється; торкнувся з порожнім каменем — у чергу вікон іде питання `soulCatch`. Порожні камені — лічильник `state.runeStones`, камені з душею — `hero.soulStones`, вставлений камінь — `Item.stone`. Камінь у зброї задає стихію автоатаки (`basicElement`): так воїн і чарівник отримують стихії; лучникові — коли стріли звичайні. Квест мандрівника вимагає `requires.flag: 'soulSeen'` — перша побачена душа. Дістати камінь — у коваля (14.4).
153. **Коваль (ROADMAP 14.4).** Ковалі — у даних (`SMITH.at`), ціни ростуть з рідкістю й рівнем речі. «Підняти рівень» веде до верху діапазону найважчої пройденої локації — тієї ж межі, від якої рахує торговець, тож коваль не обганяє прогрес. Перекидання головної характеристики міняє лише значення, додаткової — саму характеристику (без дублів на речі), щоб річ лишалася «зброєю» чи «чоботами». Камінь вставляє й сам гравець; коваль лише дістає його за золото.
154. **Особливі речі (ROADMAP 14.5).** Дані — `src/data/uniques.ts`. Легендарка без заданого слота спершу обирає силу (найчастіше класу героя), а слот бере з неї, — так кожна легендарка має силу. Сили легендарок і бонуси комплектів — ефекти того ж типу, що в дарів (`GiftEffect`), і додаються в `effects(hero)` у `gifts.ts`: параметр скіла «не менше за», характеристика, стихія. Афікс «+1 до рангу» піднімає ранг, з яким скіл працює (`effectiveRank`, не вище 5), «−X% перезарядки» множить перезарядку (не менше 50%). Афікс обирає скіл класу героя в момент падіння, тож `rollItem` отримує клас. Комплект Лісу — шанс, що річ мінібоса чи боса Лісу стане частиною комплекту (зберігає рідкість і характеристики, отримує назву частини).
155. **Лупа як ставка (ROADMAP 14.6).** Афікс тепер може випасти на будь-якій речі, крім легендарної (звичайна — рідко), і лишається прихованим до розпізнавання — тож кожна нерозпізнана річ може щось ховати. Скупник (`BLIND_BUYER`, Ізидор) купує всі нерозпізнані речі разом за 80% ціни розпізнаної — більше за торговця (50%), але без лупи й без шансу на знахідку. Розпізнавання нічого не докидає в момент лупи: усе вирішено при падінні, лупа лише показує, — так результат не залежить від того, коли гравець дивиться.
156. **Сховище (ROADMAP 14.7).** `state.stash` — одне на всі міста, до `STASH.size` речей, відкривається кнопкою в місті (B). Воно входить у контрольну точку разом із сумкою героя: інакше після смерті річ, перенесену в сховище після останнього відпочинку, можна було б отримати двічі (і в сумці з контрольної точки, і в сховищі).
157. **Смерекове (ROADMAP 15.1).** Ланцюжок міста — 4 кроки: вовки → спори → Ватажок → «Чорне джерело» (староста; зачистити Моховий яр і розповісти мисливцеві). Останній крок не дублює головний квест про Ената, а готує його сюжетно: аура йде з-під коренів, Ената треба звільнити. Дошка доручень — окремий NPC на кожне місто (`forestBoard`), бо доручення місцеві; столична дошка лишається з новинами й своїми дорученнями.
158. **Події навали (ROADMAP 15.2).** `src/systems/invasion.ts` перевіряє події щоразу, коли минає день (`completeBattle`): набіг на випадкову пройдену локацію **фронту** (краю найслабшого живого боса — там, де герой воює зараз) кожні 7 днів після 25% (не відбитий вчасно — `resetClears`), захоплений край на 50% і напад на місто на 75% — кожне раз за гру. Край обирається за порядком у `INVASION_EVENTS.captured.quests` — перший із живим босом і квестом, що його відбиває (зараз лише Ліс; інші краї додадуться з їхніми квестами). Вороги набігу й захопленого краю — звичайний розклад локації, сильніший на 25%, а третина хвилі замінюється мертвими налітниками: окремих арен для мерців не треба. Бій біля воріт — арена найлегшої локації краю (три хвилі), а його кінець не позначає ту локацію пройденою. Новини навали лежать у `state.invasionNews` і показуються, коли герой відкриває карту. Бот спершу йде на готового боса, потім відбиває набіги, потім — нові локації; з набігами по всьому світу (і кожні 3 дні) він бігав між ними безкінечно, а з фронтом і 7 днями забіг довший лише на ~20% (100–110 боїв проти 88).
159. **Мінібоси й Енат на аренах, легендарка Ената (ROADMAP 15.3).** Мінібоси б'ються в лігві (останній арені походу), Енат — у передпокої й на своїй арені з колом пнів; боси — звичайні тіла бою, тож перешкоди й рельєф діють на них без окремого коду. Власна легендарка боса (`LegendaryDef.boss`) не трапляється серед випадкових легендарок і завжди падає при першій перемозі над ним — понад звичайний лут боса; її сила не прив'язана до класу.
160. **Розвиток міст (ROADMAP 15.4).** Рівні міста — дані (`src/data/growth.ts`): ціна, захист від навали (менше хвиль у бою біля воріт), знижка в крамниці цього міста. Новий сервіс і вигляд — частини розкладки міста з полем `growth` (будівлі, пропси, жителі), які `grownLayout` показує з потрібного рівня: так «кузня з ковалем» — це просто будівля й NPC у даних. Рівні — частина контрольної точки, як і заплачене за них золото. Фон міста кешується за складом розкладки, тож розбудоване місто перемальовується.
161. **Бот 2.0: бій і похід (ROADMAP 15.5, перший блок).** Бот-стрілець перевіряє лінію видимості (`lineOfSight`): дерево між ним і ціллю — обходить боком і ближче, а не стріляє в кору. Колючки обходить (поворот ліворуч чи праворуч), воду — ні: струмок може перетинати всю арену. Лучник-бот обирає з вивчених стріл ті, що б'ють ціль найсильніше. На розвилці — невикористаний вівтар, далі скарб, а поранений (< 50% HP) — арену без більшої засідки. Гравця це не стосується: керує він сам.
162. **Бот 2.0 у місті (ROADMAP 15.5, другий блок).** `scripts/botTown.ts`: бот «говорить» з кожним жителем міста через `withQuests` — бере, звітує й здає квести тими самими пунктами діалогу, що й гравець, тож нові квести бот підхоплює без коду. Далі — продаж трофеїв, замовлення скупника, Еліксир повернення й еліксир-баф, камені (спершу у зброю — стихія), коваль, розвиток міста; бот лишає собі запас золота на зілля. Під час перевірки знайшовся баг: класові квести пропонувались будь-якому класу — `questsOffered` тепер перевіряє `classId`. Тарадайкою бот їде з міста, якщо інше відоме місто хоча б на 2 кроки ближче до цілі (`botCoach`).

Поточні цілі зрізу виконані: зі скілами 50–70% перемог над босом після 6 проходжень гаю, без скілів — менше 15%. Бот натискає скіли, щойно вони готові, і не ухиляється від телеграфів свідомо, тож живий гравець, що вибирає момент для Ривка, виграє частіше.

Небезпечна сума: до змін на 13-й хвилі 33 вороги (≈15 вовків по 11.6, 8 грибів по 11.6, пеньки по 19) за секунду знімали 300+ HP, коли оточували героя. Тепер на 13-й хвилі 23 вороги, а сильні удари мають попередження.
