# Експедиція

2D-рогалик з автобоєм і кампанією: герой б'ється сам, гравець вирішує, коли використати скіли. Бачення — [VISION.md](VISION.md), план — [ROADMAP.md](ROADMAP.md).

**Гра в реворку.** Брифінг і ухвалені рішення — [REWORK.md](REWORK.md); поки його блоки не вирішено, VISION і ROADMAP описують стару гру.

Документи:
- [docs/DECISIONS.md](docs/DECISIONS.md) — рішення прототипу (чому код зроблено саме так);
- [docs/BALANCE_LOG.md](docs/BALANCE_LOG.md) — журнал балансу й масштаб шкоди;
- [docs/SIM_RESULTS.md](docs/SIM_RESULTS.md) — останні показники симуляції;
- [docs/LORE.md](docs/LORE.md), [docs/LORE_STORY.md](docs/LORE_STORY.md) — лор;
- [docs/ART_PROMPTS.md](docs/ART_PROMPTS.md) — промпти для арту;
- [docs/archive/](docs/archive/) — старі плани (етапи 0–8 і 9–19), ТЗ, зріз, опис світу до реворку.

## Запуск

```bash
npm install
npm run dev        # гра на http://localhost:5173
npm run build      # typecheck + production-збірка в dist/
npm run preview    # перегляд збірки
npm run typecheck  # tsc --noEmit
npm test           # vitest
npm run sim        # симуляція 200 повних забігів (класи по черзі)
npm run sim -- --no-skills          # бот без скілів
npm run sim -- --runs 60 --seed 42 --class mage  # кількість, seed, один клас
npm run probe                       # на якій хвилі гине бот (один візит у Тихий гай з 1-го рівня)
npm run probe -- --endless --level 10  # нескінченний режим: як глибоко заходить герой 10 рівня
```

**Вікі** — `wiki.html` поруч із грою (у dev: `http://localhost:5173/wiki.html`; на сайті — `…/Expedition/wiki.html`; кнопка «Вікі гри» у вікні «Як грати» та на паузі). Сторінка будується з `src/data`: класи, скіли з рангами, пасивки, гілки, вороги, боси й мінібоси з атаками, локації з мобами й механіками, міста й розмови NPC, речі й шанси луту, зілля, хвилі, погода, формули та всі групи `balance.ts` з коментарями. **У `npm run dev` числа й тексти можна міняти прямо у вікі** (назви міст, локацій, ворогів, скілів, описи, репліки NPC): підкреслене — клік, нове значення, `Enter` (`Shift+Enter` — новий рядок у довгому тексті, `Esc` — скасувати). Dev-сервер (`scripts/wikiPlugin.ts`) знаходить значення як літерал у `src/data/*.ts` (`src/wiki/literal.ts`) і переписує файл, зберігаючи лапки й екрануючи їх; сторінка й гра перезавантажуються. Обчислені значення (`1 / 60`, спред, шаблони з `${…}`) не редагуються. Спільні репліки NPC («Бувай.», «Торговець») — у `NPC_LINES` (`src/data/npcs.ts`): правка змінює їх у всіх. Імена в текстах — посилання (`{town:capital}`, `{npc:capitalGuard}`, `{boss:enat:acc}` — `src/data/names.ts`): перейменування у вікі змінює їх у всіх репліках, квестах і лорі; відмінки (`forms`) правляться поруч із назвою. Лор — `src/data/lore.ts`, квести — `src/data/quests.ts`, трофеї й замовлення скупника — `src/data/trophies.ts`. Новий розділ або поле даних — у `src/wiki/sections.ts` / `src/wiki/story.ts` (`v(число, [ГРУПА, ...шлях], формат)`, `t(текст, [ГРУПА, ...шлях])`).

Seed пригоди видно в дебаг-панелі (`` ` `` у dev). Задати його можна через URL: `http://localhost:5173/?seed=123`.

## Деплой (GitHub Pages)

Кожен пуш у `main` запускає `.github/workflows/deploy.yml`: `npm ci` → typecheck → тести → `npm run build` → публікація `dist/` на GitHub Pages. Гра доступна за адресою `https://yuk1teru.github.io/Expedition/` (можна додавати `?seed=123`). Відносні шляхи в збірці задає `vite.config.ts` (`base: './'`). Одноразово в репозиторії треба увімкнути **Settings → Pages → Source: GitHub Actions**. Дебаг-панель у публічній збірці вимкнена.

## Керування

| Дія | Клавіша / миша |
|---|---|
| Перейти в локацію | клік по сусідньому вузлу карти |
| Пройти локацію ще раз | клік по поточному вузлу |
| Рух героя | `WASD` / стрілки (сам герой не ходить) |
| Напрямок автоатаки | курсор миші на арені (курсор поза ареною — атака триває в останньому напрямку) |
| Скіли | `1`–`4` або клік по слоту внизу (курсор над панеллю — скіл летить у його бік) |
| Напрямок Ривка й Удару об землю | курсор миші на арені (курсор поза ареною — автонаведення) |
| Переставити скіли | перетягнути слот мишею на інший слот (зокрема на порожній) |
| Вийти з локації | у перерві між хвилями (після 3-ї) підійти до порталу на краю арени і натиснути «Увійти» або `E` |
| Не чекати перерву / портал | `N` або кнопка «Наступна хвиля зараз» / «Не йти в портал — далі»; пропущені секунди знімаються з перезарядки скілів і ривка черевиків |
| Повернутися з карти в місто | `Esc`, кнопка «← До міста» або клік по Місту |
| Інвентар | `Tab` (на карті, в місті, в бою — гра на паузі) |
| Місто | `WASD` / клік по землі — ходити; `E` або клік по NPC — розмова (пункти — клік або `1`–`4`, `Esc` — закрити); брама або `M` — карта світу |
| Вдягнути / розпізнати річ | перетягнути річ на фігуру чи слот, або ПКМ → «Вдягнути» / «Розпізнати»; лупу можна перетягнути на нерозпізнану річ |
| Трава й зілля | `Z` / `X` / `C` у бою — що стоїть на слотах, обирається в інвентарі (перетягнути або ПКМ → «Поставити на…») |
| Фірмовий скіл | `R` (після підвищення на 13-му рівні) |
| Порівняння речей | навести на річ у сумці й затиснути `Shift` (як у WoW): поруч — підказка одягненої речі, у підказці речі — різниця характеристик |
| Ривок черевиків | `Shift` — ривок у напрямку руху (стоїте — куди дивиться герой); зелені черевики й кращі |
| Торговець | NPC у кожному місті, пункт розмови «Покажи товари»: купити лупу, зілля (мале / звичайне / велике) або випадкову річ для обраного слота (120 зол., зелена–епічна, одразу розпізнана); клік по речі в сумці — меню «Розпізнати / Вдягнути / Продати за N зол.» (у інвентарі поверх торговця — те саме в ПКМ-меню); `Tab` — повне спорядження поверх торговця |
| Пауза | `Esc` або кнопка «Пауза»; на паузі — список керування і «Завершити забіг (поразка)» |
| Швидкість ×1/×2 | кнопка в правому верхньому куті бою |
| Вибір картки / класу | клік або `1`–`3` (перші 1.5 с вибір заблоковано); `R` — перекинути картки за золото; наведіть на скіл — усі 5 рангів |
| Вибір стартових скілів | клік або `1`–`8`, `Enter` — підтвердити |
| Кнопки меню | клік, `Tab` + `Enter`, гарячі клавіші (`1`–`4` у розмові, `Enter` на екранах результатів, `Esc` у спорядженні) |
| Дебаг-панель (лише `npm run dev`) | `` ` `` |

Дебаг-панель: +1 рівень, +1000 золота, вбити всіх, безсмертя, перейти до боса, скинути лічильник проходжень гаю. У dev-збірці стан гри доступний у консолі як `window.__app`.

## Структура

```
src/
  main.ts            вхід: полотно, ввід, App
  core/              RNG (mulberry32 + fork), seed, стан забігу, екрани й модальні вікна, цикл, ввід, шина подій
  data/              УСІ числа і контент: balance, biomes, enemies, skills, classes, promotions, bosses,
                     items, consumables, weather, fx, changelog
  systems/           логіка без DOM: mapgen, run, battle, combat, ai, allies, collision, waves, hazards,
                     leveling, scaling, targeting, effects, cards, boss, hero, promotion, items, pickups
  systems/skills/    реєстр скілів (index.ts), спільні хелпери (common.ts) і реалізації: warrior, mage,
                     archer, promotion (фірмові скіли гілок)
  systems/bosses/    поведінка босів і мінібосів (enat, alpha, galeSpirit, sandWorm, scorpionKing,
                     poisonMother, bigToad, iceKnight, frostWarden), реєстрація в index.ts
  render/            полотно, UI-примітиви, екрани, HUD, ефекти, модальні вікна, дебаг-панель
scripts/sim.ts       безголова симуляція; scripts/route.ts — бот повного забігу; scripts/bot.ts — бій ботом;
                     scripts/probe.ts — смерті бота по хвилях у Тихому гаю
tests/               rng, mapgen, formulas, cards, boss, biomes, waves, skills, classes, promotion, progress, pickups, controls, version
```

Логіка (`src/core`, `src/systems`, `src/data`) нічого не імпортує з `src/render` і не звертається до DOM/window — тому `npm run sim` працює в Node.

## Як додати контент

- **Скіл**: запис у `SKILLS` (`src/data/skills.ts`) — `classId`, `targeting`, `aimable` (летить до курсора), `moves` (рух героя; блокується капканом), `icon`, опис з `{param}` / `{param%}`, `base` (ранг 1) і 4 `upgrades` (ранги 2–5; 3 і 5 — з `text`, це особливий модифікатор). Реалізація — функція `SkillImpl` у `src/systems/skills/<клас>.ts` (повертає `false`, якщо немає цілі — тоді перезарядка не витрачається), додайте її в об’єкт класу й, за потреби, новий `SkillIcon` у `src/render/icons.ts` / `classIcons.ts` та ефекти в `src/render/skillFx.ts`. Щоб скіл випадав у картках — додайте id у `skills` класу (`src/data/classes.ts`).
- **Картку**: окремих карток немає — картки «Новий скіл», «Покращення» й «Пасивка» генеруються з пулу класу (і гілки після підвищення) у `src/systems/cards.ts`. Нова пасивка — запис у `PASSIVES` (`stat`, `value` за стак, `maxStacks`) + id у `passives` класу чи гілки; новий `stat` обробіть у `recomputeHeroStats` (`src/systems/hero.ts`).
- **Ворога**: запис у `ENEMIES` (`src/data/enemies.ts`) з архетипом і рисою (`dash`, `volley`, `stomp`, `cripple`, `poison`, `split`, `shotSlow`), id — у `enemies` біому (`src/data/biomes.ts`), колір — у `palette.enemies`. Форму малює `drawEnemy` за архетипом.
- **Боса чи мінібоса**: запис у `BOSSES` (`src/data/bosses.ts`) — статистики, `phase2`, `melee`, `coldAura`, таблиця атак (`weight`, `cooldown` по фазах, `params` по фазах, `followUp` для комбо); поведінка — `registerBoss('<id>', { attacks, canUse })` у `src/systems/bosses/<id>.ts` + рядок в `index.ts`. Інструменти: `addTelegraph` / `addShapedTelegraph` (коло, лінія), `bossDash`, `bossBusy`, `spawnEnemy`, `addPuddle` / `addRing` (`hazards.ts`). Вигляд — художник у `src/render/biomeBosses.ts` (або `bossView.ts`). Призначте `boss` чи `miniboss` біому.
- **Гілку підвищення**: запис у `PROMOTIONS` (`src/data/promotions.ts`) з `effect` (новий вид обробіть у `src/systems/promotion.ts`), фірмовий скіл (з `branch`) і дві пасивки гілки.
- **Місто й NPC**: макет міста — `TOWNS` у `src/data/towns.ts` (id = id вузла світу: будинки, вода, декор, NPC, брама, точка появи); NPC і розмови — `NPCS` у `src/data/npcs.ts`: вузли з реплікою та пунктами, пункт веде на інший вузол (`next`) і/або виконує дію (`openShop`, `openChangelog`, `openInventory`, `close`; нові дії — у `runAction` у `src/render/townView.ts`). Тест перевіряє, що до брами й кожного NPC можна дійти.
- **Біом**: запис у `BIOMES` — палітра, 8 назв локацій, назва лігва боса, 3 вороги, мінібос, бос, декор; id — у `BIOME_ORDER`.

## Де міняти баланс і контент

- **Список оновлень («Що нового») і версія гри** — `src/data/changelog.ts`: на кожне оновлення, яке побачать гравці, додайте запис нагору (версія, дата, заголовок, короткі пункти). Версія першого запису — це версія гри (видно у верхній панелі). Гравець при вході бачить усі записи, новіші за ту версію, яку він бачив востаннє (`localStorage`, ключ `expedition.lastSeenVersion`); у столиці весь список відкриває дошка оголошень.

- **Числа героя, прогресії, хвиль, масштабування, загрози (днів і босів), золота, симуляції** — `src/data/balance.ts`.
- **Вороги** — `src/data/enemies.ts` (запис з архетипом `chaser | shooter | tank | fast` і рисою: `dash`, `volley`, `stomp`, `cripple`, `poison`, `split`, `shotSlow`); список ворогів, мінібос і бос біому — `src/data/biomes.ts`.
- **Скіли й пасивки** — `src/data/skills.ts` (параметри рангу 1, правило рангу 2 і модифікатор рангу 3); реалізація — функція в `src/systems/skills/<клас>.ts`, зареєстрована в `src/systems/skills/index.ts`.
- **Класи** — `src/data/classes.ts` (пул скілів і пасивок для карток).
- **Боси** — `src/data/bosses.ts` (статистики, таблиця атак з вагами, кулдаунами й параметрами по фазах) + поведінка в `src/systems/bosses/<бос>.ts` через `registerBoss`.
- **Відчуття** (тряска, хіт-стоп, частинки, цифри) — `src/data/fx.ts`.
- **Речі, рідкості, типи, таблиці здобичі, ціни продажу, рівень предмета** — `src/data/items.ts` (`ITEM_LEVEL.byTier`: рівень речей від tier локації) (вигляд — `src/render/itemArt.ts`). **Лупа, трава, зілля, швидкі слоти, рослинки** — `src/data/consumables.ts`. **Хвилі, портал, додаткові хвилі** — `WAVES` у `src/data/balance.ts`; **події 5-ї хвилі, пастки** — `WAVE_EVENTS`, `TRAPS` там само; **погода** — `src/data/weather.ts`; **риси ворогів** (стрибок, віяло, тупотіння, сповільнення, отрута, розпад, сповільнювальні постріли) — поля `dash`, `volley`, `stomp`, `cripple`, `poison`, `split`, `shotSlow` у `src/data/enemies.ts`. **Світ** (вузли на глибині, tier, макет карти, загроза босів) — `WORLD` у `src/data/balance.ts`. **Гілки підвищення** — `src/data/promotions.ts`. **Мінібос локації** — поле `miniboss` біому + запис у `src/data/bosses.ts` (`miniboss: true`) + поведінка в `src/systems/bosses/`.
